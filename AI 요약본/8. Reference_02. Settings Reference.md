# AI Settings Reference 요약

- 원문: https://code.visualstudio.com/docs/agents/reference/ai-settings
- 문서 제목: AI settings reference
- 원문 수정일: 2026-08-19

## 일반·Chat 설정

AI 기능 전체는 `chat.disableAIFeatures`, command center는 `chat.commandCenter.enabled`로 조정한다. Chat에서는 locale, terminal 출력 위치, artifacts, checkpoints, 자동 수락, 알림, queue·steer 동작을 설정할 수 있다.

## 맞춤화와 Agent 설정

`chat.hookFilesLocations`, `chat.useCustomAgentHooks`, `chat.useAgentsMdFile`, `chat.useClaudeMdFile`로 customization 파일과 hook을 조정한다. `chat.subagents.allowInvocationsFromSubagents`로 서브에이전트 중첩을 제어하며 최대 깊이는 5단계다.

Agent 관련 핵심 설정은 `chat.agent.enabled`, `chat.agent.maxRequests`, `github.copilot.chat.agent.autoFix`다.

## Inline suggestions와 모델

`github.copilot.enable`과 NES, code shifting, toolbar, 표시 지연 설정으로 inline suggestions를 관리한다. utility model, BYOK utility model, thinking effort와 language model picker 설정으로 기능별 모델을 조정한다.

## MCP·세션·브라우저

MCP discovery, 접근, sampling, MCP Apps 설정을 제공한다. Session sync, local index, browser tools와 관련된 설정도 포함한다. `chat.sessionSync.enabled`, `chat.mcp.access`, `chat.mcp.discovery.enabled`, `workbench.browser.enableChatTools` 등이 대표적이다.

## 주의 사항

Preview·Experimental·Deprecated 설정은 버전별 동작과 이름이 달라질 수 있으므로 현재 문서를 확인한다. 조직 관리 정책은 사용자 설정보다 우선할 수 있다.

## 핵심 요약

AI settings reference는 Agent, Chat, 모델, MCP, 세션, 브라우저, 맞춤화 기능의 세부 설정을 모은 참조다. 설정을 변경하기 전 적용 범위, Preview 상태, 조직 정책 우선순위를 확인해야 한다.
