# How Models Work 개념 요약

- 원문: https://code.visualstudio.com/docs/agents/concepts/language-models
- 문서 제목: Understand language models
- 원문 수정일: 2026-09-16

## 핵심 개념

언어 모델은 텍스트를 입력으로 받아 또 다른 텍스트를 생성하는 모델이다. VS Code에서는 사용자의 메시지, 대화 기록, 파일 내용, 도구 출력, 사용자 지침 등을 모두 결합해 모델에 전달한다.

중요한 점은, 모델 자체가 파일을 직접 읽거나 코드를 직접 실행하지는 않는다는 점이다. 모델은 “다음 행동을 제안”하거나 “도구를 호출하라”는 텍스트를 생성하고, VS Code가 실제 도구를 실행한다.

## 1. 모델의 특성

언어 모델은 다음 특성을 가진다.

- 비결정적: 같은 입력이어도 결과가 매번 다를 수 있음
- 컨텍스트 의존적: 제공된 정보의 품질이 결과에 큰 영향을 줌
- 지식 경계: 학습 시점 이후의 내용을 정확히 알지 못함

그래서 모델은 보통 코드베이스 맥락, 문서, 테스트 결과, 최근 대화 기록 등을 제공받아야 정확한 답을 내린다.

## 2. Context Window

컨텍스트 창은 한 번의 요청에 모델이 처리할 수 있는 정보의 총량을 말한다.

포함되는 요소:

- 시스템 지침
- 사용자 메시지
- 대화 이력
- 커스텀 인스트럭션
- 참조한 파일 내용
- 도구 출력

컨텍스트가 꽉 차면, VS Code는 오래된 대화를 요약해서 공간을 확보한다. 필요하면 `/compact` 명령으로 직접 압축할 수 있다.

## 3. 추론(Thinking)

일부 모델은 답을 바로 내리기 전에 내부적으로 더 깊게 생각할 수 있다. 이를 reasoning 또는 thinking이라고 한다.

- 간단한 작업: 빠른 응답이 더 효율적
- 복잡한 작업: 설계, 디버깅, 리팩터링, 다단계 분석에서는 reasoning이 유용

`Thinking effort`로 모델의 추론 강도를 조절할 수 있다. 높은 값은 더 깊게 사고하지만 토큰 사용량과 지연이 증가할 수 있다.

## 4. 모델 선택

작업에 따라 적절한 모델을 선택해야 한다.

- 빠른 모델: 단순 코드 생성, 작은 수정
- 추론 모델: 복잡한 리팩터링, 아키텍처 설계, 다단계 디버깅
- 큰 컨텍스트 모델: 큰 코드베이스나 긴 대화에 유리

VS Code는 Auto model selection 기능을 제공해 작업을 적절한 모델에 자동 라우팅할 수 있다.

## 5. AI credits / 비용

GitHub Copilot은 모델별로 AI credits 사용량이 다르다. 더 강력한 모델일수록 더 많은 크레딧을 소비한다.

비용에 영향을 주는 요소:

- 모델 선택
- thinking effort
- 컨텍스트 크기
- 사용된 도구와 반복 작업
- 프롬프트 캐싱 활용 여부

## 6. BYOK(Bring Your Own Key)

기본 모델이 만족스럽지 않으면, 직접 API 키를 연결해 다른 모델 제공자를 사용할 수 있다.

장점:

- 더 많은 모델 선택권
- 로컬 모델 사용 가능
- 특정 제공자의 기능 실험 가능

주의:

- 일부 기능(예: inline suggestions, semantic search)는 GitHub Copilot 서비스가 필요할 수 있음
- 모델별로 기능이 다를 수 있음

## 7. 요약

언어 모델은 컨텍스트를 바탕으로 추론하고, 에이전트가 도구를 통해 실제 행동을 수행하는 핵심 엔진이다. 모델 선택, 컨텍스트 구성, 추론 수준, 비용 관리가 모두 고품질 AI 작업의 핵심 요소다.
