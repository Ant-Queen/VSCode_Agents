## 언어 모델의 기본

언어 모델은 프롬프트를 입력으로 받아 텍스트를 생성한다. VS Code에서는 사용자 메시지, 대화 기록, 파일 내용, 도구 결과, 사용자 지정 지침 등이 함께 조합되어 모델에 전달된다.

모델은 파일을 직접 읽거나 실행하지 않는다. 대신, 어떤 도구를 호출할지 결정하고, VS Code가 해당 도구를 실행한 뒤 결과를 다시 모델에 전달한다.

## 중요한 특성

- 비결정성: 같은 입력이라도 매번 다른 답변이 나올 수 있다.
- 컨텍스트 의존: 문맥이 좋을수록 품질이 향상된다.
- 지식 경계: 학습 시점 이후 정보는 부족할 수 있다.

## 컨텍스트 윈도우

모델이 한 번의 요청으로 처리할 수 있는 전체 정보량을 컨텍스트 윈도우라고 한다. 시스템 프롬프트, 대화 기록, 참조 파일, 도구 결과 모두 이 범위 안에 들어간다.

대화가 길어지면 VS Code는 오래된 내용을 자동으로 요약해서 공간을 확보한다. 필요하면 `/compact` 명령으로 수동 압축도 가능하다.

## 추론(Thinking)

일부 모델은 답변을 바로 내기 전에 내부적으로 더 깊게 추론한다. 이를 "thinking" 또는 "reasoning"이라고 부른다.

- 빠른 모델: 단순 편집, 보일러플레이트, 간단한 질문
- 추론 모델: 복잡한 디버깅, 리팩터링, 아키텍처 판단
- 큰 컨텍스트 모델: 대규모 코드베이스나 긴 대화에 적합

## 모델 선택

VS Code는 작업 성격에 따라 모델을 선택할 수 있다.

- 빠른 모델: 신속한 수정
- 추론 모델: 복잡한 문제 해결
- 큰 컨텍스트 모델: 대규모 이해가 필요한 작업

GitHub Copilot의 Auto model selection은 작업 난이도와 모델 가용성을 기반으로 적절한 모델을 선택한다.

## 비용과 크레딧

Copilot 플랜은 AI 크레딧을 사용한다. 모델의 종류, 토큰 수, 추론 수준, 도구 사용, 프롬프트 캐싱 등에 따라 소비량이 달라진다.

## BYOK

기본 제공 모델이 부족하면 API 키를 직접 연결해 다른 제공업체의 모델을 사용할 수 있다. 이를 BYOK(Bring Your Own Key)라고 한다.

장점:

- 다른 모델 제공업체의 모델 사용
- 로컬 모델 실행 가능
- 특정 기능이나 새 모델 실험

주의점:

- 모델별 지원 기능이 다름
- 안전 필터링이 보장되지 않을 수 있음

## 핵심 요약

언어 모델은 입력된 맥락을 바탕으로 다음 행동을 결정하는 추론 엔진이며, VS Code는 이를 에이전트 루프, 도구, 권한, 세션과 결합해 실제 개발 작업을 수행하게 만든다. 모델 선택은 속도, 비용, 복잡성, 컨텍스트 요구사항을 기준으로 해야 한다.
