## 코드베이스 이해의 핵심

Copilot 에이전트는 코드베이스를 이해하기 위해 여러 검색 도구를 사용한다. 단순 키워드 검색뿐 아니라 의미 기반 검색을 활용해 관련 코드를 찾는다.

## 검색 및 읽기 도구

에이전트가 보통 쓰는 도구는 다음과 같다.

- Semantic search (`#codebase`): 의미 기반 탐색
- Text search: 텍스트 패턴 검색
- Grep: 정규식 기반 탐색
- File search: 파일명/패턴 기반 탐색
- Usages: 정의와 참조 추적
- List directory: 디렉터리 구조 탐색
- Read file: 특정 파일 내용 읽기

에이전트는 한 번에 전체 코드를 읽는 대신, 필요한 범위만 좁혀서 검색하고 읽는 방식을 사용한다.

## 세맨틱 인덱스

정확한 키워드에만 의존하지 않고 의미적으로 유사한 코드를 찾기 위해 워크스페이스 인덱스를 만든다. 대규모 프로젝트에서는 이 인덱스가 매우 중요하다.

인덱스는 자동으로 생성되고 관리되며, 아직 인덱스가 없을 때도 다른 검색 도구로 충분히 동작한다.

## 제외 설정의 중요성

검색 품질을 높이려면 다음 설정을 잘 관리해야 한다.

- `.gitignore`
- `files.exclude`
- `search.exclude`

이 설정을 잘 활용하면 불필요한 빌드 산출물, 로그, 대용량 데이터를 검색에서 제외시켜 컨텍스트 낭비를 줄일 수 있다.

## 프롬프트가 검색 전략에 미치는 영향

질문을 구체적이고 코드 용어에 맞게 쓰면 에이전트는 더 정확한 검색과 관련 파일 탐색을 수행한다.

예를 들어 "이 함수가 어디서 호출되나"보다 "payment service에서 오류 처리 방식은 어디에 있나"처럼 구체적인 질문이 더 좋은 결과를 낳는다.

## 비공개 저장소와 보안

비공개 저장소를 탐색할 때는 추가 인증이 필요할 수 있다. 권한이 부여된 이후에는 세션이 저장되어 유지된다.

## 핵심 요약

에이전트는 구조적 검색, 의미 기반 검색, 인덱싱, 파일 읽기 조합으로 코드를 이해한다. 워크스페이스에 대한 적절한 검색 전략과 제외 설정은 정확도와 비용 효율을 크게 개선한다.
