# Sessions & Handoff 개념 요약

- 원문: https://code.visualstudio.com/docs/agents/concepts/sessions
- 문서 제목: Understand agent sessions and handoff
- 원문 수정일: 2026-09-16

## 핵심 개념

세션은 에이전트 작업의 단위다. 대화, 작업 상태, 코드 변경, 실행 환경이 하나의 세션 안에 묶여 있다. 이 세션을 기준으로 작업을 관리하고, 필요하면 다른 환경이나 다른 에이전트로 넘길 수 있다.

## 1. 세션이란

세션은 하나의 작업 단위로, 다음 요소를 함께 가진다.

- 대화 기록
- 작업의 현재 상태
- 코드 변경 내용
- 실행 환경(로컬, 원격, Dev Container 등)

세션은 독립적이라서 여러 작업을 동시에 돌릴 수 있고, 서로 간섭하지 않는다.

## 2. 한 세션 안의 여러 채팅

한 세션에는 여러 채팅을 넣을 수 있다. 각 채팅은 별도의 대화 기록을 가지지만, 동일한 작업 영역과 코드 환경을 공유한다.

예:

- 채팅 A: 기능 구현
- 채팅 B: 테스트 작성

두 채팅은 같은 코드베이스를 기준으로 작업할 수 있지만, 서로의 대화 기록은 자동 상속되지 않는다. 필요 시 요구사항을 새 프롬프트에 명시해야 한다.

## 3. 여러 세션 관리

세션은 독립적으로 관리되기 때문에 다음이 가능하다.

- 여러 작업을 동시에 실행
- 세션 복제(Fork)로 대안 실험
- 체크포인트를 사용해 이전 상태 복원
- 현재 작업을 다른 세션으로 넘기기

## 4. Chat view와 Agents window

VS Code의 Chat view와 Agents window는 같은 세션을 공유한다. 즉, 어떤 화면에서 작업하든 같은 세션을 계속할 수 있다.

- 한 화면에서 세션 시작
- 다른 화면에서 이어하기
- 작업 흐름을 브라우저, 터미널, 에디터와 연결

## 5. Handoff(핸드오프)

핸드오프는 현재 세션을 다른 구성으로 이어가는 기능이다.

예:

- Copilot 세션을 Claude나 Codex로 이동
- Plan agent에서 설계 후 구현 에이전트로 이어주기
- 클라우드에서 실행이 더 적합한 작업으로 이동

핸드오프는 대화 기록과 맥락을 그대로 유지하면서, 실행 환경이나 모델/하니스를 바꾼다.

## 6. 원격/동기화 세션

세션은 로컬 머신에만 있는 것이 아니라, 원격 호스트, Dev Container, 클라우드 환경에서도 실행될 수 있다.

- 원격 세션: 다른 머신에서 실행
- 동기화 세션: GitHub 계정을 통해 장치 간 접근 가능
- 세션 히스토리: 이전 작업을 추적하고 회고 가능

## 7. 요약

세션은 에이전트 워크를 구조화하는 기본 단위이며, 핸드오프 기능을 통해 작업 흐름을 다른 모델, 환경, 또는 역할로 자연스럽게 이어갈 수 있다. VS Code는 이러한 세션을 여러 화면과 환경에서 일관되게 관리한다.
