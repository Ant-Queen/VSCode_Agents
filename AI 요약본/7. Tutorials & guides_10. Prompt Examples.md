# Prompt Examples 요약

- 원문: https://code.visualstudio.com/docs/agents/guides/prompt-examples
- 문서 제목: Prompt examples
- 원문 수정일: 2026-08-19

## 기능별 선택

- **Ask**: 일반 개념, 기술, 코드베이스 질문
- **Agent**: 여러 파일 생성·수정, 명령 실행, 테스트가 필요한 작업
- **Inline Chat**: 현재 위치의 국소 편집

## 코드베이스 탐색

`#codebase`를 사용해 인증 흐름, 데이터베이스 설정, 빌드 방법, 테스트 프레임워크를 탐색한다. 함수명·파일명·심볼을 함께 적으면 결과가 더 정확하다.

## 생성·테스트·디버깅

`#styles.css` 같은 파일을 참조해 UI를 추가하고, `#testFailure`나 `#problems`를 첨부해 테스트·진단 문제를 수정한다. Source Control의 `#changes`로 변경사항을 요약하거나 커밋 메시지·릴리스 노트를 만들 수 있다.

## 외부 자료와 노트북

외부 문서는 `#fetch URL`, GitHub 코드 예시는 GitHub MCP server로 참조한다. 노트북은 `/newNotebook`, 데이터셋은 `#housing.csv`처럼 파일을 첨부해 요청한다.

## 효과적인 프롬프트

목표, 기술 스택, 입력과 출력 형식, 관련 context, 제약, edge case, 검증 기준을 구체적으로 적는다. 큰 작업은 생성·검증·수정·테스트를 여러 프롬프트로 나누고, Agent에게 실패 시 수정 후 전체 검증을 반복하도록 요청한다.

## 핵심 요약

좋은 프롬프트는 작업 규모에 맞는 Chat 표면과 정확한 context를 선택하고, 원하는 결과와 완료 조건을 관찰 가능하게 표현한다. 모호한 “더 좋게” 대신 파일·기술·동작·예상 결과를 직접 지정해야 한다.
