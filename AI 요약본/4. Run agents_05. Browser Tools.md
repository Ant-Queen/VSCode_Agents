# Browser Tools 요약

- 원문: https://code.visualstudio.com/docs/agents/run/browser-tools
- 문서 제목: Use browser tools with agents
- 원문 수정일: 2026-08-19

## 브라우저 도구란

Browser tools는 에이전트가 웹 애플리케이션을 소스 코드만으로 추론하지 않고 실제 화면과 상호작용으로 검증하게 하는 VS Code 내장 기능이다. 외부 MCP 서버가 필요하지 않으며, 개발 서버 실행부터 수정·검증·재수정까지 닫힌 피드백 루프를 제공한다.

## 검증 루프

1. 에이전트가 애플리케이션 코드를 변경한다.
2. 개발 서버를 시작하거나 실행 중인 앱을 찾는다.
3. 통합 브라우저에서 페이지를 열고 상호작용한다.
4. 페이지 내용, 접근 가능한 요소, 스크린샷, 콘솔 오류와 결과를 분석한다.
5. 문제를 수정하고 같은 검사를 반복한다.
6. 테스트한 내용과 결과를 보고한다.

## 가능한 작업

- 페이지 열기, URL 이동, 라우트 간 링크 따라가기
- 페이지 콘텐츠와 접근 가능한 요소, 콘솔 오류 읽기
- 버튼 클릭, 텍스트 입력, hover, drag, dialog 처리
- 레이아웃 확인을 위한 스크린샷 캡처
- 복잡한 흐름을 위한 Playwright 코드 실행

주요 도구는 `openBrowserPage`, `navigatePage`, `readPage`, `screenshotPage`, `clickElement`, `hoverElement`, `dragElement`, `typeInPage`, `handleDialog`, `runPlaywrightCode`다.

## 시작하기

`workbench.browser.enableChatTools`가 켜져 있어야 한다. Chat view나 Agents window에서 새 에이전트 세션을 시작하고, 앱을 실행할 방법과 URL, 수행할 사용자 흐름, 예상 결과, 실패 시 수정·재검증 여부를 프롬프트에 포함한다.

좋은 프롬프트는 다음을 명시한다.

- 앱을 시작하는 명령과 열 URL
- 수행할 사용자 여정
- 각 단계의 기대 결과
- 중요한 경계 조건과 데스크톱·모바일 뷰포트
- 문제가 발견되면 수정할지 여부
- 수정 후 반복할 검증

## 브라우저 세션

- **에이전트가 연 페이지**: 쿠키와 저장소를 공유하지 않는 비공개 메모리 세션이다. 로컬 앱, 공개 페이지, 비인증 흐름에 적합하다.
- **사용자가 공유한 페이지**: 기존 탭의 쿠키, 저장소, 로그인 상태를 사용한다. 인증이나 상태가 필요한 흐름에 적합하다.

사용자가 통합 브라우저에서 **Share with Agent**를 선택해야 기존 탭을 에이전트에 공개할 수 있다. 에이전트가 연 페이지는 다른 탭과 격리된다.

## 피드백과 컨텍스트

브라우저의 **Add to Chat**에서 요소의 HTML·CSS·스크린샷, 요소별 의견, 화면 캡처, 콘솔 로그를 채팅에 추가할 수 있다. Browser tools는 에이전트가 자율적으로 탐색하는 흐름에, Add to Chat은 사용자가 특정 시각·오류 컨텍스트를 지정하는 흐름에 적합하다.

## 개인정보와 조직 제어

에이전트가 명시적으로 승인한 탭만 공유할 수 있고, 에이전트가 연 탭은 임시 격리 저장소를 사용한다. 신뢰하지 않는 작업 공간의 통합 브라우저는 항상 임시 저장소를 사용한다. 조직은 BrowserChatTools 정책과 네트워크 필터링으로 브라우저 도구와 접근 도메인을 제한할 수 있다.

## 문제 해결

도구가 보이지 않으면 `workbench.browser.enableChatTools`를 확인하고 Configure Tools에서 Built-in > Browser 도구를 선택한다. 로그인 페이지에 접근하지 못하면 기존 탭을 Share with Agent로 공유한다. 도메인 접근 실패는 네트워크 필터나 조직 정책을 확인한다.

반복 가능한 검사는 CI에서 실행할 Playwright 등 자동화 테스트로 저장하는 것이 좋다.

## 핵심 요약

Browser tools는 웹 앱의 실제 사용자 흐름, 화면, 콘솔 상태를 에이전트가 직접 검증하게 한다. 앱 실행 방법과 관찰 가능한 완료 조건을 구체적으로 제시하고, 인증 상태가 필요하면 사용자가 기존 브라우저 탭을 명시적으로 공유해야 한다.
