# Troubleshoot AI in VS Code 요약

- 원문: https://code.visualstudio.com/docs/agents/agent-troubleshooting/troubleshooting
- 문서 제목: Troubleshoot AI in Visual Studio Code
- 원문 수정일: 2026-08-19

## 로그와 진단

`Developer: Set Log Level`에서 Copilot과 Copilot Chat을 Trace로 설정하고 Output 채널을 확인한다. 네트워크·방화벽·프록시·VPN 문제는 `GitHub Copilot: Collect Diagnostics`로 진단한다.

`/troubleshoot`는 Agent Debug Log를 분석하며 `github.copilot.chat.agentDebugLog.enabled`가 필요하다. 로그에는 도구 호출, LLM 요청, 토큰, customization 발견, 오류가 시간순으로 기록된다.

## Chat Debug와 MCP

Chat Debug view에서 raw system prompt, user prompt, context, tool payload를 확인한다. MCP 문제는 `MCP: List Servers`에서 서버 상태, Show Output, Restart Server를 확인한다.

로그와 debug snapshot에는 프롬프트와 코드 같은 민감 정보가 포함될 수 있으므로 공유 전에 검토한다.

## 문제 보고

재현 단계, 오류 메시지, 관련 로그와 환경 정보를 수집한 뒤 Issue Reporter로 제출한다. VS Code와 관련 확장을 최신 상태로 유지하고, 구독·로그인·조직 정책·네트워크를 함께 확인한다.

## 핵심 요약

AI 문제는 로그 수준을 높이고 Agent Debug Logs·Chat Debug view·MCP 서버 출력을 비교해 원인을 좁힌다. 디버그 자료에는 민감 정보가 포함될 수 있으므로 공유 전 정제하고, 재현 가능한 단계와 함께 보고해야 한다.
