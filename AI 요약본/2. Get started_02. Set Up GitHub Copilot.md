# Set Up GitHub Copilot 요약

- 원문: https://code.visualstudio.com/docs/setup/copilot
- 문서 제목: Set up GitHub Copilot in VS Code
- 원문 수정일: 2026-09-16

## 문서 핵심

VS Code에서 GitHub Copilot을 설정하는 방법을 설명하는 문서다. Copilot은 GitHub 계정과 연결되어 사용하며, 계정 유형, 사용량, 데이터 처리, AI 기능 활성화 등을 함께 고려해야 한다.

## 1. 사전 확인 사항

설치 전 알아두어야 할 항목은 다음과 같다.

- GitHub 계정과 Copilot 플랜 필요
- 조직에서 제공하는 Copilot이 있으면 해당 정책을 따라야 함
- Copilot Free를 사용할 수 있는 경우 가입 가능
- 사용량과 과금 구조는 모델, 플랜, BYOK 방식에 따라 다름
- 데이터 처리 방식은 GitHub Copilot Trust Center와 조직 정책을 확인해야 함

또한 Copilot이 아닌 다른 모델을 쓰고 싶다면 BYOK(Bring Your Own Key) 방식을 사용할 수 있다. 이 경우 별도의 모델 공급자 계약과 결제 조건이 적용된다.

## 2. Copilot 설정 절차

VS Code에서 설정하는 기본 흐름은 다음과 같다.

1. Status Bar의 Copilot 아이콘 위에 마우스를 올림
2. Use AI Features 선택
3. 로그인 방법 선택
4. 이미 구독 중인 계정이면 연결
5. 구독이 없으면 Copilot Free 플랜으로 가입 가능

설정 후에는 VS Code에서 Copilot 관련 기능을 바로 사용할 수 있다.

## 3. 프로젝트 준비(선택 사항)

채팅 세션에서 `/init`을 입력하면 프로젝트용 맞춤형 지침(custom instructions)을 자동 생성할 수 있다. 이 설정은 코드베이스를 분석해 프로젝트의 코딩 관례를 반영하는 데 도움이 된다.

## 4. GitHub Enterprise 계정 사용

GitHub Enterprise(GHE) 계정을 사용하는 경우, GHE 인증 방식을 선택해 Copilot에 로그인할 수 있다.

- Status Bar에서 Use AI Features 선택
- GHE 인스턴스 URL과 자격 증명 입력
- 필요 시 다른 GitHub 계정으로 전환 가능

## 5. 계정 전환

서로 다른 GitHub 계정을 Copilot에 연결하고 싶다면 다음과 같이 처리한다.

- Accounts 메뉴에서 현재 GitHub 계정 로그아웃
- 다시 Sign in with GitHub 선택
- 또는 Command Palette에서 GitHub Copilot: Sign in 실행

워크스페이스 또는 프로필별로 다른 계정을 지정할 수도 있다.

## 6. 워크스페이스/프로필별 계정 설정

다음 설정 방식을 사용할 수 있다.

- Accounts 메뉴 → Manage Extension Account Preferences
- GitHub Copilot Chat 선택
- 해당 워크스페이스/프로필에 사용할 GitHub 계정 선택

GitHub Enterprise 계정은 JSON 설정에서 `github.copilot.advanced`의 `authProvider`를 설정해 사용할 수 있다.

## 7. AI 기능 비활성화

필요한 경우 VS Code 전체 또는 특정 워크스페이스에서 AI 기능을 비활성화할 수 있다.

- 설정값: `chat.disableAIFeatures`
- 사용자 수준 또는 워크스페이스 수준 적용 가능
- Chat 메뉴에서 AI 기능 숨기기 옵션 사용 가능

## 8. 다음 단계

설정이 끝나면 다음 단계로 Quickstart를 진행할 수 있다.

- AI 기능을 체험하는 첫 작업 수행
- 에이전트가 코드 수정 및 브라우저 검증을 하도록 실습

## 핵심 요약

GitHub Copilot 설정은 단순히 로그인하는 단계가 아니라, 계정 정책, 사용량, 데이터 처리, 프로젝트별 설정까지 함께 점검하는 과정이다. 이후 VS Code에서 자주 쓰는 AI 기능을 모두 활용할 수 있게 만드는 첫 단계라고 볼 수 있다.
