# AI Overview 요약

- 문서 제목: Build with AI in VS Code
- 원문 수정일: 2026-09-16

## 문서 핵심

VS Code에서 AI는 단순한 코드 자동완성 도구를 넘어서, 코드 이해, 버그 수정, 기능 구현, 리팩터링, 테스트까지 하나의 개발 워크플로우로 통합한다. 사용자는 채팅으로 질문하거나, 에이전트에게 작업을 위임하고, 결과를 검토하며 필요한 범위에서 최종 결정을 내릴 수 있다.

## 1. AI로 무엇을 할 수 있나

AI는 아래와 같은 작업에 활용될 수 있다.

- 기능 구현, 버그 수정, 다중 파일 리팩터링
- 코드베이스 이해 또는 탐색
- 변경 전 설계 검토 및 계획 수립
- 에디터 안에서의 집중적인 변경
- 입력 도중의 인라인 추천
- 커밋 메시지 생성, 선택 코드 설명 등 반복적 작업 자동화

즉, AI는 작업의 단위와 복잡도에 따라 대화형 Chat, 인라인 제안, 에이전트 작업으로 이어질 수 있다.

## 2. 에이전트는 어떻게 동작하나

에이전트는 언어 모델을 기반으로 요청을 해석하고, 코드, 오류 메시지, 테스트 결과 등 다양한 컨텍스트를 수집한 뒤 작업 환경에서 행동한다.

핵심 흐름은 다음과 같다.

1. 사용자가 요청을 보냄
2. 에이전트가 관련 코드와 상황을 파악함
3. 필요한 수정 또는 실행을 수행함
4. 결과를 검토하고 필요하면 다시 수정함
5. 사용자가 최종 변경을 승인하거나 반려함

이 반복 과정을 에이전트 루프(agent loop)라고 하며, 오류를 수정하거나 테스트를 다시 실행하는 등 검증 중심의 반복 작업이 핵심이다.

### 세션(Session)

각 작업은 세션 단위로 관리된다. 세션은 대화와 변경 이력을 함께 보관하여, 나중에 다시 돌아와 작업을 이어가거나 별도 작업으로 분리할 수 있게 한다.

## 3. 에이전트로 작업하는 방식

### 채팅 뷰에서 작업하기

작업 중인 프로젝트에서 Chat view를 열면 대화와 코드 편집을 동시에 진행할 수 있다. 디버거, 터미널, 테스트 결과를 같은 흐름 안에서 활용할 수 있어 가장 기본적이고 편리한 인터페이스다.

### 에이전트 창에서 작업하기

Agents window는 여러 세션을 한눈에 관리하고 작업 위임에 적합한 인터페이스다. 여러 프로젝트나 작업을 동시에 추적하면서 진행 상황을 확인할 수 있다.

### 기타 접근 방식

- 터미널 기반 작업: Copilot CLI
- 원격 세션 또는 클라우드 세션
- 브라우저 접근이 필요한 작업
- GitHub Copilot 앱 같은 별도 데스크톱 환경

## 4. 모델, 에이전트, 도구 선택

VS Code는 모델, 에이전트 하니스, 도구를 조합해서 사용한다.

- 모델: 추론 능력, 속도, 비용에 맞춰 선택
- 에이전트 하니스: Copilot, Claude, Codex 등 도구와 워크플로우가 다른 환경 선택
- 모델 접근: GitHub Copilot 플랜, BYOK, 로컬 모델 등 다양한 옵션
- 도구와 커스터마이징: 프로젝트 지침, MCP 서버, 에이전트 스킬, 플러그인 등 확장

중요한 점은 모델 자체와 도구 실행 환경이 서로 다를 수 있다는 것이다. 에이전트가 로컬 파일을 수정하면서도 원격 모델에 요청을 보낼 수 있다.

## 5. 사용자는 여전히 통제권을 가진다

AI는 실수를 할 수 있으므로, 최종 책임은 사용자에게 있다.

- 변경 전 리뷰: diff를 확인하고 결과를 검증한 뒤 커밋
- 승인 및 권한: 민감한 행동은 확인 절차를 거칠 수 있음
- 중지 가능: 작업을 멈출 수 있지만, 이미 완료된 행동은 되돌리지 못할 수 있음
- 격리와 보안: Git worktree는 변경 분리를 돕지만 보안 경계가 아님
- 샌드박싱: 파일 시스템, 네트워크 제한 등을 점검해야 함
- 조직 정책: 회사 정책에 따라 사용할 수 있는 에이전트, 모델, 도구가 제한될 수 있음

## 6. 권장 워크플로우

VS Code 공식 문서는 다음 순서로 시작할 것을 권장한다.

- 첫 번째 에이전트 작업을 수행한다
- 작은 앱을 만들고 검증한다
- 결과를 리뷰하고 수정한다
- 점차 실제 프로젝트에 적용한다

## 요약

이 문서는 “VS Code에서 AI를 어떻게 개발 도구로 사용할지”를 소개하는 입문 문서다. AI는 코드 이해, 버그 수정, 기능 구현, 테스트, 리팩터링까지 지원하며, 사용자는 대화형으로 작업을 지시하고 에이전트가 실수를 줄이도록 검증하는 방식으로 활용한다. 핵심은 “AI를 신뢰하는 것”이 아니라 “AI를 제어하면서 검증하고 선택적으로 반영하는 것”이다.
