# Agents Tutorial 요약

- 원문: https://code.visualstudio.com/docs/agents/agents-tutorial
- 문서 제목: Tutorial: Agentic coding in VS Code
- 원문 수정일: 2026-09-16

## 문서 핵심

이 문서는 VS Code에서 에이전트를 사용해 실제 프로젝트를 만들어보는 튜토리얼이다. 에이전트 창과 채팅 뷰를 함께 사용하면서, 에이전트가 파일을 생성하고 수정하고, 브라우저에서 결과를 검증하며, Git 변경 사항을 확인하고 커밋하는 과정을 학습한다.

## 1. 준비 사항

- VS Code 설치
- AI 기능 활성화
- Git 설치
- GitHub Copilot 계정 또는 무료 플랜

튜토리얼에서는 `myportfolio`라는 새 프로젝트 폴더를 만들고, 이를 Git 저장소로 초기화한 뒤 작업한다.

## 2. 프로젝트 폴더 생성

다음 절차를 따른다.

1. 새 폴더 생성: `myportfolio`
2. 터미널에서 `git init` 실행
3. VS Code의 Agents window에서 해당 폴더를 선택

이때 폴더를 신뢰할지 묻는 창이 나오면 확인한다.

## 3. Agents window에서 시작

Agents window는 에이전트 중심 워크플로우를 위한 전용 인터페이스다.

- New 버튼으로 새 세션 생성
- 폴더 선택
- Copilot agent harness 선택
- Agent 역할, 언어 모델, 권한 설정 확인

세션 생성 후, 아래 같은 프롬프트를 입력하면 된다.

```text
Create a personal portfolio page with HTML, CSS, and JavaScript in separate files. Include a header with my name and a short bio, a section for projects with cards, and a contact section. Use modern styling and add some sample content.
```

에이전트는 페이지를 구성하는 파일들을 생성하고 수정한다.

## 4. 브라우저로 미리보기

Agents window의 Files 탭에서 `index.html`을 선택한 뒤, Open in Integrated Browser를 실행한다. 이렇게 하면 VS Code 내부 브라우저에서 결과를 바로 확인할 수 있다.

다음 단계로는 아래와 같은 방식으로 디자인을 조정한다.

- 브라우저에서 요소 선택
- Add Element to Chat로 해당 요소를 대화 컨텍스트에 추가
- 프롬프트로 색상, 글꼴, 레이아웃 변경 요청
- 브라우저 새로고침으로 즉시 확인

## 5. 변경 사항 검토 및 커밋

에이전트가 수정한 결과는 Changes panel에서 확인할 수 있다.

- 변경된 파일 목록 확인
- diff 열기
- 특정 코드 블록에 대해 피드백 입력
- 커밋 메시지 생성 및 Commit Changes 수행

이 과정에서 피드백을 주면 에이전트가 다시 수정해준다.

## 6. 에디터로 이어서 작업

Agents window에서 세션을 열어두고, 이후에는 Chat view로 넘어가서 코드 중심 작업을 계속할 수 있다.

예시 프롬프트:

```text
Add an accessible theme switcher button that toggles between light and dark color themes. Persist the selected theme across page reloads, update the button label to describe the theme it applies, and keep the layout responsive on narrow screens.
```

이후 Source Control view에서 변경사항을 검토하고, 브라우저에서 접근성, 반응형 동작, 테마 유지 여부를 다시 확인한다.

## 7. 핵심 학습 포인트

이 튜토리얼은 에이전트 사용 방식의 두 가지 흐름을 보여준다.

- 에이전트 우선형: Agents window에서 작업을 위임
- 코드 중심형: 에디터에서 작업하면서 Chat view로 보조 받기

두 방식을 같은 세션에서 이어가며, 브라우저 검증과 Git 커밋까지 한 흐름으로 다룬다.

## 핵심 요약

이 튜토리얼은 “에이전트가 코드를 작성하고, 브라우저로 동작을 검증하고, 변경사항을 리뷰하며, Git에 커밋까지 수행하는” 전체 개발 흐름을 실습한다. 가장 실용적인 사용법을 배우는 문서로 볼 수 있다.
