# Add Context to Chat 요약

- 원문: https://code.visualstudio.com/docs/chat/copilot-chat-context
- 문서 제목: Add context to chat
- 원문 수정일: 2026-08-19

## 컨텍스트 추가

명시적 context를 추가하면 AI가 작업에 필요한 파일, 폴더, 심볼, 이미지, 웹 콘텐츠를 정확히 고려한다. Chat 입력에서 `#`을 입력하거나 Add Context를 선택해 항목을 지정한다.

추가할 수 있는 컨텍스트는 다음과 같다.

- 파일·폴더·심볼
- `#codebase` 전체 코드베이스
- 도구·MCP 서버
- 터미널 출력·테스트 실패·진단 오류·Source Control 변경
- 이미지, 브라우저 HTML 요소·스크린샷·console log
- URL과 `#fetch` 웹 콘텐츠

Explorer, Search, 편집기 탭에서 항목을 Chat으로 드래그할 수도 있다.

## Chat participant와 웹 컨텍스트

`@vscode`, `@terminal` 같은 `@` mention으로 전문 participant를 호출한다. URL을 프롬프트에 포함하거나 `#fetch`로 현재 웹 문서를 가져올 수 있으며, 외부 URL 접근에는 승인 절차가 적용된다.

`#codebase`는 전체 코드베이스를 의미 검색 컨텍스트로 요청한다. 작업에 필요한 파일·심볼을 함께 지정하면 결과가 더 집중된다.

## 이미지와 브라우저

이미지를 첨부해 시각적 문제를 설명할 수 있다. 통합 브라우저에서는 요소를 선택해 HTML, CSS, 선택적 이미지와 스크린샷을 Chat에 보낸다. `chat.sendElementsToChat.attachCSS`, `attachImages`로 첨부 범위를 조절한다.

기존 브라우저 페이지를 공유하면 쿠키와 로그인 상태가 전달될 수 있으므로 비공개 정보가 포함되지 않았는지 확인한다. 에이전트가 연 페이지는 별도 임시 세션을 사용한다.

## 효과적인 사용

프롬프트의 목표와 대상 파일을 구체적으로 적고, 필요한 context만 추가한다. 전체 코드베이스를 무조건 첨부하기보다 관련 파일·심볼·오류·예상 결과를 선택한다. 외부 문서는 신뢰할 수 있는 URL인지 확인하고 응답 내용도 검토한다.

## 핵심 요약

Context는 모델이 볼 수 있는 작업 자료를 명시적으로 조절하는 장치다. `#` mention, Add Context, drag-and-drop, 브라우저 요소 첨부를 사용해 필요한 정보만 제공하면 정확도와 보안성을 함께 높일 수 있다.
