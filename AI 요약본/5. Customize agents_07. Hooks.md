# Agent Hooks 요약

- 원문: https://code.visualstudio.com/docs/agent-customization/hooks
- 문서 제목: Agent hooks in Visual Studio Code (Preview)
- 원문 수정일: 2026-08-19

## Hook의 역할

Hook은 에이전트 생명주기의 특정 이벤트에서 셸 명령을 실행하는 결정적 맞춤화다. 자동 포맷, 보안 명령 차단, 감사 로그, 승인 제어처럼 모델이 기억해야 하는 지침보다 반드시 실행되어야 하는 동작에 적합하다.

## 지원 이벤트

`SessionStart`, `UserPromptSubmit`, `PreToolUse`, `PostToolUse`, `PreCompact`, `SubagentStart`, `SubagentStop`, `Stop` 이벤트를 지원한다.

- PreToolUse: 도구 실행 전 검증·차단·입력 수정
- PostToolUse: 도구 실행 후 검사·추가 컨텍스트
- SessionStart: 세션 시작 시 정보 주입
- Stop/SubagentStop: 종료 조건 확인

## 파일과 실행 형식

Workspace hook은 `.github/hooks/*.json`, 사용자 hook은 `~/.copilot/hooks` 등에 둔다. Claude 형식과 plugin hook도 지원한다.

각 명령은 stdin으로 JSON을 받고 stdout으로 JSON을 반환한다. 설정에는 `type: "command"`, `command`, `cwd`, `env`, `timeout`, `windows`, `linux`, `osx`를 사용할 수 있다.

종료 코드 `0`은 성공, `2`는 차단, 그 외는 비차단 경고로 처리된다. 출력은 `continue`, `stopReason`, `systemMessage`, `hookSpecificOutput` 같은 공통 결과를 사용할 수 있다.

## 권한과 입력 제어

PreToolUse hook은 `allow`, `deny`, `ask`로 실행 여부를 제어하고 `updatedInput`으로 도구 입력을 수정할 수 있다. PostToolUse는 추가 컨텍스트를 제공하거나 후속 처리를 block할 수 있다.

Hook은 에이전트가 수정·실행할 수 있는 스크립트이므로 `chat.tools.edits.autoApprove`에서 hook 파일을 보호하고 출처를 검토한다. Custom agent frontmatter의 agent-scoped hook은 Preview이며 `chat.useCustomAgentHooks`가 필요하다.

## 사용 사례

- 파일 편집 후 formatter 실행
- 위험한 `rm -rf`나 `DROP TABLE` 명령 차단
- 도구 호출과 변경 사항 감사 로그 기록
- 민감한 도구 호출에 사용자 확인 요구
- 세션 시작 시 프로젝트 규칙 또는 환경 정보 추가

`Stop`과 `SubagentStop`에서 계속 실행을 차단할 때는 `stop_hook_active`를 확인해 무한 반복을 방지한다.

## 핵심 요약

Hook은 에이전트 생명주기에 결정적 동작을 삽입한다. 모델 지침과 달리 항상 실행되므로 보안 정책·감사·검증에 유용하지만, hook 자체도 명령 실행 권한을 가지므로 파일 보호와 입력 검증이 필요하다.
