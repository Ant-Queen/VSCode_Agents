# Agents Window 요약

- 원문: https://code.visualstudio.com/docs/agents/run/agents-window
- 문서 제목: Use the Agents window
- 원문 수정일: 2026-10-07

## Agents window의 용도

Agents window는 여러 작업 공간의 세션을 한 창에서 시작·추적하고 변경 결과를 검토하는 전용 VS Code 창이다. 여러 프로젝트를 오가며 작업을 배정하는 agent-first 흐름에 적합하다. 한 프로젝트의 코드 편집·디버깅·테스트가 중심이면 Chat view를 쓸 수 있으며 두 화면은 같은 세션을 공유한다.

## 열기와 화면 구성

제목 표시줄의 **Open in Agents**, 명령 팔레트의 `Chat: Open Agents window`, `code --agents` 명령으로 연다. 브라우저에서는 `https://insiders.vscode.dev/agents`를 사용할 수 있다. 브라우저 창은 GitHub 로그인이 필요하다.

사이드바의 세션 목록, Customizations 패널, 대화 영역, Changes 패널, Files 패널을 중심으로 사용한다. 세션을 바꾸면 파일·diff·터미널·Tasks·Browser가 해당 세션의 작업 공간 기준으로 전환된다. 작업 공간이 없는 Quick chat에는 Files와 Changes가 표시되지 않는다.

## 세션 시작과 추적

**New** 또는 `Ctrl+N`으로 시작해 폴더, 저장소, 원격 작업 공간 또는 GitHub 이슈·PR을 선택한다. 작업 공간을 지정하지 않는 Quick chat도 가능하다. 사용 가능한 harness, agent, 모델, 권한, 격리 방식을 설정하고 프롬프트를 보낸다. `Alt+Enter`는 현재 세션을 떠나지 않고 새 작업을 백그라운드에서 시작한다.

세션은 작업 공간·시간별로 묶거나 사용자 지정 그룹으로 정리하고, 고정하거나 드래그해 순서를 바꿀 수 있다. 여러 세션을 격자 형태로 열어 비교할 수 있으며, 세션 안의 다중 채팅을 나란히 배치하는 것도 지원한다.

## 결과 검토와 마무리

Files에서 작업 공간 파일을 살펴보고 Changes에서 브랜치 변경, 미커밋 변경, 전체 변경 또는 마지막 에이전트 턴의 diff를 검토한다. 통합 브라우저, 터미널, Tasks, 테스트로 검증한 뒤 커밋하거나 PR을 만든다. PR 생성 폼에서 draft와 수동 병합·자동 병합 등의 흐름을 선택할 수 있다.

## 인증과 제한

기본적으로 GitHub 인증이 필요하다. 데스크톱에서는 설정 및 사용 가능한 자격 증명에 따라 Claude, ChatGPT 기반 Codex, BYOK 모델을 GitHub 로그인 없이 쓰는 실험 기능이 제공된다. 다중 루트 세션은 아직 지원되지 않으며 Cloud 세션은 GitHub 저장소와 연동된다.

## 핵심 요약

Agents window는 여러 작업 공간의 세션을 조정하고 변경 사항·검증·PR을 한곳에서 관리한다. 세션을 독립적으로 격리할지 확인하고, 완료 뒤 Changes와 실제 실행 결과를 검토한 다음 통합한다.
