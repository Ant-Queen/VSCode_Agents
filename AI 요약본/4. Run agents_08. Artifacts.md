# Artifacts 요약

- 원문: https://code.visualstudio.com/docs/agents/run/artifacts
- 문서 제목: Agent artifacts (Preview)
- 원문 수정일: 2026-08-19

## 아티팩트란

Artifacts panel은 스크린샷, 계획, 문서처럼 중요한 리소스를 채팅 옆에서 확인하게 하는 기능이다. Chat view와 Agents window 모두에서 사용할 수 있으며, 여러 출처의 아티팩트를 출처별 그룹 트리로 합쳐 표시한다.

사용하려면 `chat.artifacts.enabled`를 `true`로 설정한다. 현재 Preview 기능이다.

## 아티팩트 출처

- **규칙 기반 추출**: 대화의 MIME 유형, 파일 경로 glob, memory 파일 경로를 설정에 맞춰 자동 추출한다.
- **에이전트 지정**: 에이전트가 `#artifacts` 도구로 명시한 리소스를 표시한다. 에이전트가 목록을 갱신하면 이전 목록은 교체된다.
- **서브에이전트 지정**: 서브에이전트별 아티팩트를 이름이 표시된 별도 그룹으로 보여준다.

## 추출 규칙 설정

| 설정 | 기준 | 기본 예 |
| --- | --- | --- |
| `chat.artifacts.rules.byMimeType` | 도구 결과 MIME 패턴 | `image/*`를 Screenshots로 그룹화 |
| `chat.artifacts.rules.byFilePath` | 작업 공간 파일 glob | `**/*plan*.md`를 Plans로 그룹화 |
| `chat.artifacts.rules.byMemoryFilePath` | memory 쓰기 경로 glob | 계획 memory 파일을 Plans로 그룹화 |

예를 들어 `chat.artifacts.rules.byFilePath`에 `**/*.html`을 추가하면 에이전트가 작성한 HTML 파일을 Web Pages 그룹으로 표시할 수 있다. 세 규칙을 모두 `{}`로 설정하면 자동 추출을 끌 수 있다.

## 사용 방법

아티팩트가 있으면 대화 옆에 패널이 나타난다. 이미지는 미리보기로 열리고 문서는 편집기에서 열린다. 규칙 기반 아티팩트는 대화가 진행될 때 자동으로 갱신되며, 규칙을 바꾸면 현재 패널도 새 규칙을 반영한다.

자연어로 다음과 같이 요청할 수 있다.

- `Take a screenshot of my app and set it as an artifact`
- `Write a project plan and set it as an artifact`
- `Save these links as artifacts`

에이전트는 필요한 경우 `#artifacts` 도구를 선택한다. 현재 세션의 규칙을 일시적으로 바꾸려면 `#artifactRules` 도구를 사용할 수 있다.

## 핵심 요약

Artifacts panel은 대화 중 생성된 스크린샷·계획·문서·링크를 중요한 결과물로 모아 보여준다. 규칙 기반 자동 추출과 에이전트·서브에이전트의 명시적 지정을 조합해 작업 결과를 빠르게 다시 열 수 있다.
