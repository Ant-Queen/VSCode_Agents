# Configure the Agents Window 요약

- 원문: https://code.visualstudio.com/docs/agents/run/agents-window-configuration
- 문서 제목: Configure the Agents window
- 원문 수정일: 2026-10-07

## 계정과 모델

Agents window는 VS Code 본 창의 계정, 모델 자격 증명, 기본 프로필과 설정을 공유하며 별도의 공급자 설정을 두지 않는다. GitHub Copilot은 계정 메뉴에서 로그인하고, Codex는 ChatGPT 계정으로 로그인한다. Claude와 BYOK 모델은 각자 지원 자격 증명을 구성해야 한다.

데스크톱에서는 실험 설정 `chat.agentHost.allowSignedOutWhenUsable`을 켜면 Claude·Codex·BYOK로 GitHub 로그인 없이 사용할 수 있다. 브라우저 기반 Agents window는 GitHub 로그인이 필요하다.

## 창 전용 설정과 레이아웃

Agents window에서 Settings를 열어 적용 범위를 확인한다. 공통 VS Code 설정 중 필요한 값을 Agents window에만 재정의할 수 있다.

- `sessions.editor.wordWrap`으로 코드 편집기의 줄 바꿈을 상속·켜기·끄기 중 선택한다. `Alt+Z`는 현재 파일만 임시 전환한다.
- 실험적 단일 패널 레이아웃은 `sessions.layout.singlePaneDetailPanel`을 켜고 창을 다시 열어 사용한다. 편집기와 Changes·Files 상세 보기 탭을 한 패널에 표시한다.
- `sessions.layout.autoCollapseSessionsSidebar`는 좁은 창에서 세션 사이드바를 자동으로 접는다.

## 새 세션 화면

실험 기능인 `sessions.chat.experimental.welcomePhrases`로 환영 문구를 표시하고 이름·문구를 설정할 수 있다. `sessions.chat.experimental.newSessionComposerLayout`은 작업 공간, 브랜치, worktree, harness 제어를 입력창 위에 묶어 보여준다. 이 레이아웃은 unified workspace picker 설정이 필요하다.

## Markdown과 확장

`workbench.editor.markdownDefaultEditorInAgentsWindow`로 `.md` 파일을 실험적 Markdown Editor 또는 렌더링 미리보기 중 무엇으로 열지 정한다. Markdown Editor에서는 편집·잠금 모드를 전환하고 Git 변경 표시를 확인할 수 있다.

확장은 기본 VS Code 프로필에 설치되어야 한다. 정적 콘텐츠 제공 확장은 자동 활성화되며, 다른 확장은 `extensions.supportAgentsWindow`에 확장 ID를 지정해 사용한다. 확장 지원은 계속 발전 중이다.

## 핵심 요약

Agents window는 본 창의 계정과 설정을 공유하면서 일부 레이아웃과 편집 동작을 창 단위로 조정할 수 있다. 실험 설정은 버전 변경 가능성이 있으므로 필요한 항목만 명시적으로 활성화한다.
