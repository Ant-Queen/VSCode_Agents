# MCP Configuration 요약

- 원문: https://code.visualstudio.com/docs/agents/reference/mcp-configuration
- 문서 제목: MCP configuration reference
- 원문 수정일: 2026-08-19

## 설정 파일

MCP 서버 설정은 workspace의 `.vscode/mcp.json` 또는 사용자 프로필의 `mcp.json`에 저장한다. 최상위 구조는 `servers`, 선택적 `inputs`, 선택적 `sandbox`다.

Agent Host는 `.mcp.json`과 `~/.copilot/mcp-config.json`을 직접 읽을 수 있으며, VS Code는 대화형 입력이 필요한 서버를 제외한 설정을 전달한다.

## 서버 유형

### stdio

`type: "stdio"`, `command`가 필수이고 `args`, `cwd`, `env`, `envFile`, `dev`, `sandboxEnabled`를 선택적으로 사용한다. Docker stdio 서버는 VS Code와 통신할 수 있도록 `-d` 없이 foreground로 실행한다.

### HTTP·SSE

`type`, `url`, `headers`, `oauth`로 구성한다. HTTP Stream을 우선 사용하고 필요하면 SSE fallback을 사용할 수 있다.

## 입력 변수와 보안

`${input:id}`로 API key를 포함한 입력을 분리한다. 입력은 `promptString`, `pickString`, `command` 유형으로 정의하고, 비밀번호는 `password: true`로 숨긴다. 원문 secret을 설정 파일에 커밋하지 않는다.

## 샌드박스와 개발 모드

macOS·Linux에서 sandbox의 파일 read/write와 허용·차단 네트워크 도메인을 지정할 수 있다. `dev.watch`로 변경 감시·재시작을, Node/Python stdio의 `debug`로 서버 디버깅을 설정한다.

## 관리 명령

서버 추가, 목록 확인, 재시작, 출력 보기, 리소스 탐색, 캐시 초기화, 신뢰 초기화 명령을 제공한다. 관련 설정은 `chat.mcp.access`, `chat.mcp.autostart`, `chat.mcp.serverSampling`, `chat.mcp.apps.enabled`다.

## 핵심 요약

MCP configuration은 서버 연결 방식, 환경 변수, 인증, 샌드박스와 개발 모드를 JSON으로 정의한다. `inputs`와 보안 저장소로 비밀을 분리하고, Docker·네트워크·서버 권한을 실행 전에 검토해야 한다.
