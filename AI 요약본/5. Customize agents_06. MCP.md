# MCP Servers 요약

- 원문: https://code.visualstudio.com/docs/agent-customization/mcp-servers
- 문서 제목: Add and manage MCP servers in VS Code
- 원문 수정일: 2026-08-19

## MCP 서버란

Model Context Protocol 서버는 외부 도구, 데이터, API를 에이전트에 연결한다. 서버는 tools, resources, prompts, MCP Apps를 제공하며 데이터베이스·이슈 트래커·브라우저 등 외부 시스템을 채팅에서 사용할 수 있게 한다.

## 추가 방법

- Extensions view에서 `@mcp`로 검색해 설치한다.
- `MCP: Add Server` 명령을 실행한다.
- workspace의 `.vscode/mcp.json` 또는 사용자 MCP 설정을 직접 작성한다.
- Agent Customizations editor에서 MCP 탭을 사용한다.

stdio, HTTP, SSE 서버 유형을 지원한다. API key와 같은 민감한 값은 `${input:id}` 변수로 입력받는다. Docker stdio 서버는 통신을 위해 detached `-d`가 아닌 foreground로 실행한다.

## 서버 관리

Extensions view, `MCP: List Servers`, 설정 파일의 code lens에서 서버를 시작·중지·재시작하고 출력 로그를 확인할 수 있다. 최초 실행 시 서버 신뢰를 확인하며 설정이 바뀌면 다시 확인할 수 있다.

설정 파일에서 직접 실행하면 일부 신뢰 확인이 생략될 수 있으므로 서버 출처와 명령을 먼저 검토한다. 로컬 MCP 서버는 임의 코드를 실행할 수 있다.

## 샌드박싱과 설정

macOS·Linux에서는 `sandboxEnabled`로 로컬 서버의 파일과 네트워크 접근을 제한할 수 있다. Windows에서는 MCP 서버 샌드박싱을 지원하지 않는다.

관련 설정은 `chat.mcp.discovery.enabled`, `chat.mcp.autostart`, `chat.mcp.access`, `chat.mcp.apps.enabled` 등이다. MCP 도구의 승인과 서버 신뢰는 별도로 관리한다.

## 보안 권장 사항

서버의 게시자, 저장소, 실행 명령, 환경 변수와 네트워크 접근을 확인한다. API key는 설정 파일에 직접 쓰지 말고 입력 변수나 보안 저장소를 사용한다. 불필요한 서버는 중지하거나 도구 목록에서 비활성화한다.

## 핵심 요약

MCP는 VS Code 에이전트를 외부 시스템과 연결하는 표준 확장 방식이다. 추가·실행 전 서버의 코드와 권한을 검토하고, 민감 정보는 입력 변수로 보호하며, 지원 플랫폼에서는 샌드박싱을 적용해야 한다.
