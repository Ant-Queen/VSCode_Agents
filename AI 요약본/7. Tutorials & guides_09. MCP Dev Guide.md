# MCP Developer Guide 요약

- 원문: https://code.visualstudio.com/docs/agents/guides/mcp-developer-guide
- 문서 제목: AI extensibility in VS Code
- 원문 수정일: 2026-08-19

## AI 확장 방식

VS Code 확장은 다음 방식으로 AI 기능을 확장할 수 있다.

- **Language model tool**: 에이전트가 호출하는 도구이며 확장 호스트에서 실행되어 VS Code API에 접근한다.
- **MCP tool**: 외부 MCP 서버에서 실행되어 독립 배포와 다른 MCP client 재사용이 가능하지만 VS Code API에는 직접 접근하지 않는다.
- **Chat participant**: `@` mention으로 호출되는 전문 assistant로 대화 흐름을 제어한다.
- **Language Model API**: code action, hover, custom view 등 Chat 외부 UI에 모델 기능을 통합한다.

## 선택 기준

VS Code API나 편집기 상태가 필요하면 language model tool, 독립 실행·원격 서비스·다른 클라이언트 재사용이 필요하면 MCP를 선택한다. 사용자가 명시적으로 호출하는 전문 대화 경험은 Chat participant, 편집기 기능에 직접 붙이는 AI 동작은 Language Model API가 적합하다.

## 배포 고려 사항

Marketplace 배포, 인증과 원격 통신, 도구 승인과 신뢰, 재사용 가능한 인터페이스를 설계한다. MCP 서버와 확장 도구는 실행 권한을 가질 수 있으므로 명령과 데이터 접근 범위를 문서화하고 검토해야 한다.

## 핵심 요약

VS Code의 AI 확장은 확장 호스트 내부 도구, 독립 MCP 서버, 전문 Chat participant, 직접 호출하는 Language Model API로 나뉜다. 필요한 실행 위치와 VS Code API 접근 여부를 기준으로 방식을 선택한다.
