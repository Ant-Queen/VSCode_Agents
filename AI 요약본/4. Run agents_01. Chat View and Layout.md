# Chat View and Layout 요약

- 원문: https://code.visualstudio.com/docs/agents/run/chat-view
- 문서 제목: Use the Chat view
- 원문 수정일: 2026-10-07

## Chat view의 용도

Chat view는 편집기 옆에서 에이전트와 대화하며 같은 VS Code 창에서 코드, diff, 터미널, 테스트, 디버거를 함께 사용하는 코드 중심 인터페이스다. 현재 프로젝트의 구현·검토·검증에 적합하고, Chat view와 Agents window는 같은 세션을 공유한다.

## 열기와 레이아웃

- 제목 표시줄의 Chat 메뉴에서 **Open Chat**을 선택한다.
- `Ctrl+Alt+I` 단축키를 사용하거나 명령줄에서 `code chat`을 실행한다.
- 새 채팅은 **Side bar**, **Editor tab**, **Separate window** 중 원하는 배치로 연다.

Side bar는 코드와 채팅을 나란히 사용하기 좋고, Editor tab은 넓은 화면이나 세션 비교에, 별도 창은 다중 모니터에 적합하다. Chat view의 compact 모드는 세션 목록과 대화를 같은 영역에 표시하고, side-by-side 모드는 세션 목록을 계속 표시한다.

## 화면과 세션

화면은 세션 목록, 대화 기록 및 응답, 프롬프트 입력창으로 구성된다. 입력창에서 Session Target, Agent, Language model, Permissions를 지정한 뒤 프롬프트를 보내면 작업 공간에 연결된 세션이 시작된다. 사용 가능한 선택지는 계정, 설치된 제공자, 조직 정책에 따라 달라진다.

지원되는 Agent Host 세션은 하나의 세션 안에 여러 peer chat을 포함할 수 있다. Sessions 목록에서 메인 대화를 펼쳐 채팅을 전환한다. peer chat 생성과 배치 관리는 Agents window의 다중 채팅 기능을 참고한다.

## 작업 검토

Copilot 세션은 선택한 폴더나 worktree에 변경 사항을 직접 저장한다. 응답의 변경 파일을 열어 diff를 검토하고, `chat.checkpoints.showFileChanges`를 켜면 요청별 변경 요약을 볼 수 있다. 편집기, 확장, 노트북, 디버거, Tasks, 테스트 및 원격 작업 공간도 대화와 함께 사용할 수 있다.

변경 사항을 수정·복원·통합하는 방법은 별도의 Review and Revert Changes 문서를 참고한다.

## 핵심 요약

Chat view는 현재 프로젝트에 집중해 코드를 만들고 결과를 바로 검증하는 작업 표면이다. 여러 프로젝트의 세션을 한곳에서 조정해야 할 때는 Agents window로 전환하고, 동일 세션을 계속 이어갈 수 있다.
