# Tools 요약

- 원문: https://code.visualstudio.com/docs/agents/concepts/tools
- 문서 제목: Understand tools in AI agents
- 원문 수정일: 2026-10-07

## 도구의 역할

도구는 에이전트가 정보를 수집하거나 실제 행동을 수행할 수 있게 해주는 기능이다. 모델만으로는 답변을 생성하는 것밖에 못하지만, 도구를 통해 에이전트는 다음을 할 수 있다.

- 파일 읽기/쓰기
- 코드 검색
- 터미널 실행
- 테스트 실행
- 외부 시스템과 연동

도구 호출 결과는 다음 에이전트 행동의 컨텍스트가 된다.

## 도구의 종류

VS Code에서 지원하는 도구는 크게 세 가지다.

- 내장 도구: 파일 탐색, 편집, 검색, 터미널 실행 등 VS Code가 기본 제공
- MCP 도구: Model Context Protocol 서버를 통해 외부 데이터나 시스템과 연결
- 확장 프로그램 도구: VS Code 확장이 제공하는 고급 기능

## 도구 선택 방식

기본적으로 에이전트는 현재 작업 목적과 컨텍스트를 바탕으로 적절한 도구를 선택한다. 필요한 경우 `#` 참조를 사용해 특정 도구를 직접 지정할 수도 있다.

## 도구 활성화와 제한

모든 도구가 자동으로 사용 가능한 것은 아니다. 에이전트가 필요한 능력만 활성화시키는 것이 좋다.

이유는 다음과 같다.

- 불필요한 도구 호출 방지
- 컨텍스트 창식 낭비 감소
- 잘못된 행동 위험 감소

도구 제한의 범위는 세션 방식과 실행 환경에 따라 달라진다.

## 승인과 보안

도구는 파일 수정, 터미널 실행, 외부 네트워크 접근 같은 위험한 행동을 할 수 있다. 그래서 VS Code는 다음 제어를 제공한다.

- 승인 프롬프트
- URL 승인
- 권한 수준 설정
- 허용 도구 범위 제한

## 핵심 요약

도구는 에이전트가 "생각만 하는 AI"가 아니라 실제 개발 작업을 수행할 수 있게 하는 핵심 기능이다. 다만 도구는 편리함과 동시에 권한과 보안 영향이 크기 때문에, 적절한 범위와 승인 정책을 설정해야 한다.
