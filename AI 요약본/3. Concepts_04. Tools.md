# Tools 개념 요약

- 원문: https://code.visualstudio.com/docs/agents/concepts/tools
- 문서 제목: Understand tools in AI agents
- 원문 수정일: 2026-09-16

## 핵심 개념

도구는 에이전트가 정보를 수집하거나 실제 행동을 수행하게 하는 기능이다. 모델만으로는 텍스트를 생성할 뿐이지만, 도구를 연결하면 에이전트는 파일을 읽고, 코드를 수정하고, 터미널을 실행하고, 외부 서비스와 연결할 수 있다.

## 1. 도구가 에이전트 루프에 미치는 영향

예를 들어 테스트가 실패한 문제를 수정한다고 가정해 보자.

1. 검색 도구로 관련 테스트와 코드 위치를 찾음
2. 파일을 읽어 원인 확인
3. 수정 도구로 코드 변경
4. 터미널 실행 도구로 테스트 실행
5. 결과를 기반으로 다시 수정 여부 판단

이 과정을 통해 에이전트는 단순히 답을 제안하는 대신 실제 작업을 수행하고 검증한다.

## 2. 도구의 종류

VS Code에서 사용 가능한 도구는 크게 세 가지다.

- Built-in tools: 파일 읽기/쓰기, 터미널 실행, 코드 검색 등 VS Code 자체 제공 도구
- MCP tools: MCP 서버를 통해 외부 데이터나 서비스에 연결하는 도구
- Extension tools: 확장 프로그램이 제공하는 도구

## 3. 모델이 도구를 선택하는 방식

기본적으로 에이전트는 현재 요청과 컨텍스트를 기반으로 적절한 도구를 선택한다.

- 여러 도구를 자동으로 선택하여 사용 가능
- 필요하면 프롬프트에서 `#`로 특정 도구를 직접 지정 가능
- 너무 많은 도구를 열어두면 오히려 불필요한 동작과 컨텍스트 낭비가 발생할 수 있음

## 4. 어떤 도구를 활성화할지

도구는 “사용 가능한 도구”와 “활성화된 도구”가 다르다.

- 사용 가능한 도구: 설치되어 있고 현재 세션에서 접근 가능한 도구
- 활성화된 도구: 에이전트가 실제로 선택할 수 있는 도구

권장 원칙:

- 작업과 관련된 도구만 활성화
- 불필요한 도구는 비활성화
- 너무 많은 도구는 컨텍스트 창을 낭비하고 실수 가능성을 높임

## 5. 승인 및 신뢰 관리

도구는 파일 수정, 터미널 실행, 외부 서비스 호출 등 위험한 동작을 수행할 수 있다. 그래서 VS Code는 다음을 제공한다.

- 승인 프롬프트
- URL 승인
- 권한 수준 설정
- 민감한 파일 보호

권한 수준은 작업을 어떤 정도로 자동으로 처리할지 결정한다.

- 수동 승인
- 일부 자동 승인
- 높은 자율성 모드

## 6. 요약

도구는 에이전트가 단순히 답을 제안하는 수준을 넘어 실제 작업을 수행하게 만드는 핵심 요소다. 하지만 도구는 동시에 위험 요소를 포함하므로, 적절한 선택과 승인 체계가 필수적이다. 에이전트는 좋은 도구 선택과 제어된 권한 하에서 가장 효과적으로 동작한다.
