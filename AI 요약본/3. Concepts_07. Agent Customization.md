# Agent Customization 개념 요약

- 원문: https://code.visualstudio.com/docs/agents/concepts/customization
- 문서 제목: Understand agent customization
- 원문 수정일: 2026-09-16

## 핵심 개념

AI 모델은 일반 지식은 풍부하지만, 프로젝트 고유 규칙이나 팀 관습, 외부 시스템, 반복적인 워크플로우는 모른다. 에이전트 사용자 지정(customization)은 이런 정보를 에이전트에 지속적으로 제공해, 더 나은 작업 결과를 얻도록 돕는다.

## 1. 사용자 지정이 에이전트에 주는 영향

커스터마이징은 다음 역할을 수행한다.

- 컨텍스트 제공: 프로젝트 규약, 아키텍처 설명
- 반복 작업 정의: 스킬, 프롬프트 파일
- 역할 지정: 커스텀 에이전트
- 기능 확장: MCP 서버
- 동작 강제: 훅(Hooks)

중요한 점은, `instructions`와 `hook`은 서로 다르다는 것이다. 지침은 모델의 관행을 유도하지만, 훅은 이벤트 발생 시 반드시 수행된다.

## 2. 사용자 지정 종류

### Instructions

프로젝트 전반에 적용되는 규칙을 제공한다. 예:

- 로깅 방식
- 예외 처리 방식
- 라이브러리 선택 규칙

### Agent skills

특정 작업을 수행하는 데 필요한 지침, 템플릿, 스크립트 등을 묶어 제공한다.

### Prompt files

재사용 가능한 프롬프트를 저장해 `/명령어` 형태로 쉽게 호출할 수 있다.

### Custom agents

특정 역할용 에이전트를 정의한다. 예: 보안 리뷰 에이전트, 테스트 에이전트.

### MCP servers

외부 데이터 소스/서비스와 연결하는 도구 세트를 제공한다.

### Hooks

특정 이벤트가 발생하면 자동으로 동작을 실행한다. 예: 파일 수정 후 포맷터 실행

## 3. 사용자 지정의 범위

사용자 지정은 적용 범위에 따라 나뉜다.

- User: 개인 전용, 모든 워크스페이스에서 사용
- Workspace / Repository: 프로젝트 공유용
- Organization: 조직 단위 공유

좁은 범위부터 선택하는 것이 좋다. 개인 선호는 사용자 수준, 프로젝트 표준은 워크스페이스 수준, 조직 정책은 조직 수준이 적절하다.

## 4. Model-driven vs deterministic behavior

대부분의 사용자 지정은 모델을 유도하는 방식이다.

- Instructions: 모델이 지침을 따라가도록 돕는다
- Skills: 작업 패턴을 제시한다
- Tools/MCP: 사용할 수 있는 행동을 늘린다

반면 Hook은 결정적(deterministic) 동작을 수행한다. 조건 충족 시 실행되므로 모델의 기억 여부와 무관하게 강제된다.

## 5. 조합 방식

사용자 지정은 서로 배타적이지 않고 조합될 수 있다.

예시:

1. Instructions: 코드 규칙 제공
2. Custom agent: 특정 역할 부여
3. Skill: 작업 절차 제공
4. MCP: 외부 이슈 시스템 연결
5. Hook: 검증을 강제

이처럼 각 층은 서로 다른 책임을 가진다.

## 6. 요약

에이전트 커스터마이징은 단순히 “좋은 프롬프트를 늘어놓는 것”이 아니라, 반복 작업, 팀 규칙, 외부 도구, 자동 검증 등을 프로젝트에 맞춰 구조화하는 과정이다. 잘 설계된 커스터마이징은 반복 질문을 줄이고, 더 일관된 결과를 제공한다.
