## 세션과 채팅

세션은 작업 공간, 코드 변경, 하나 이상의 대화를 묶는 작업 단위다. 새 독립 작업이나 다른 작업 공간·설정이 필요할 때 새 세션을 시작한다. Chat view와 Agents window는 같은 세션을 공유하므로 진행 중인 작업을 다른 화면에서 계속할 수 있다.

지원되는 Agent Host 세션은 여러 peer chat을 가질 수 있다. 각 채팅은 기록·제목·agent·모델은 독립적이지만 같은 폴더와 worktree의 코드를 공유한다. 변경 충돌이 우려되면 별도 worktree 세션을 사용한다. `/btw`는 Copilot·Claude의 Agents window에서 원 대화에 기록을 추가하지 않는 side chat을 연다.

## 컨텍스트 관리와 목록

컨텍스트 사용량은 입력창의 context window control에서 확인한다. 긴 대화는 자동으로 compact되며 `/compact` 또는 Compact Conversation으로 수동 요약할 수 있다. 새 세션은 컨텍스트를 초기화한다.

세션 목록은 상태, harness, 작업 공간, 변경 통계를 보여준다. 고정·그룹화·정렬·보관으로 정리할 수 있으며 Agents window에서는 모든 작업 공간, Chat view에서는 현재 작업 공간을 중심으로 표시한다. 지원되는 CLI·Copilot 앱·Claude Code·Codex 세션은 External 필터로 찾아 열 수 있다.

## 보관, 삭제, Worktree 정리

Archive 또는 Mark as Done은 세션을 활성 목록에서 숨기지만 기록을 보존해 복원할 수 있다. Worktree는 보관 과정에서 변경 보존을 시도하며 브랜치 이력은 유지된다. Delete는 되돌릴 수 없고 Copilot 세션의 worktree도 제거할 수 있으므로 변경을 먼저 통합한다.

Worktree Cleanup 편집기에서 비활성 세션을 골라 정리할 수 있다. 자동 정리 Preview 설정은 병합된 PR이 있는 비활성 세션을 Done 처리한 뒤 별도 유예 기간 후 삭제하도록 구성한다. 자동 정리는 조건을 만족하는 worktree만 제거하고 안전하지 않으면 보존한다.

## Fork와 내보내기

`/fork`는 전체 대화 기록을 복사해 갈라진 작업을 시작한다. 특정 요청의 checkpoint에서 fork하면 그 시점까지의 기록만 포함한다. Fork는 대화를 분리하지만 같은 worktree를 사용할 수 있으므로 코드 격리가 필요한지 확인한다.

Chat: Export Chat...은 대화 전체를 JSON으로 저장한다. 컨텍스트 메뉴에서 메시지 하나, 전체 대화, 마지막 도구 호출 이후의 최종 응답만 Markdown으로 복사할 수 있다.

## 핵심 요약

세션은 관련 작업의 기록과 실행 상태를 관리하고, 채팅은 세션 안의 대화 단위다. 보관은 복구 가능한 정리에, fork는 기존 맥락을 가진 대안 탐색에, 새 worktree는 코드 변경 격리에 사용한다.
