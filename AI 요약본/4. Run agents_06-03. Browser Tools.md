# Browser Tools 요약

- 원문: https://code.visualstudio.com/docs/agents/run/browser-tools
- 문서 제목: Use browser tools with agents
- 원문 수정일: 2026-10-07

## 기능과 검증 흐름

Browser tools는 VS Code 통합 브라우저에서 에이전트가 웹 앱을 열고 사용자 흐름을 수행하도록 한다. 에이전트는 코드를 바꾸고 서버를 실행한 뒤 화면·접근성 요소·콘솔 오류를 확인하며, 문제를 수정하고 같은 검사를 반복한다. 외부 MCP 서버가 필요하지 않다.

페이지 이동, 콘텐츠 읽기, 버튼 클릭·입력·hover·drag, 대화상자 처리, 스크린샷 촬영, 필요 시 Playwright 실행을 지원한다. `workbench.browser.enableChatTools`가 기본적으로 브라우저 도구를 활성화한다.

## 브라우저 세션과 개인정보

- **에이전트가 연 탭**은 쿠키·저장소를 공유하지 않는 격리된 임시 세션이다. 로컬 앱이나 공개 페이지에 적합하다.
- **사용자가 공유한 탭**은 기존 쿠키·로그인 상태를 포함한다. 통합 브라우저에서 Share with Agent를 선택하고 승인해야 접근할 수 있다.

인증이 필요한 페이지에 에이전트가 접근해야 하면 기존 탭을 명시적으로 공유한다. 공유 표시를 다시 선택해 언제든 접근을 취소할 수 있다. 신뢰되지 않은 작업 공간은 임시 브라우저 저장소를 사용한다.

## 웹페이지에서 피드백 제공

Add to Chat으로 렌더링 요소의 HTML·CSS, 요소별 코멘트, 전체 화면·영역 스크린샷, 콘솔 출력을 프롬프트에 첨부한다. Browser tools는 에이전트가 자율적으로 탐색·테스트하는 기능이고, Add to Chat은 사용자가 특정 화면 문제를 지정할 때 유용하다.

## 효과적인 검증 프롬프트

앱 실행 명령과 URL, 수행할 사용자 흐름, 단계별 기대 결과, 경계 조건, 모바일·데스크톱 크기, 문제 발견 시 수정 여부와 수정 후 재검증 기준을 명시한다. 결과가 관찰 가능한 기준이어야 완료를 판단하기 쉽다.

브라우저 탭 공유는 사용자의 승인이 필요하며, 조직은 BrowserChatTools 정책과 네트워크 필터로 도구 및 도메인을 제한할 수 있다. 브라우저 검증은 빠른 반복에 쓰고 회귀 방지가 필요하면 Playwright 등의 자동화 테스트를 저장소에 추가한다.

## 핵심 요약

Browser tools는 코드만이 아니라 실제 웹 화면과 사용자 동작으로 변경을 검증한다. 인증이 필요한 기존 세션은 직접 공유하고, 재현 가능한 흐름은 자동화 테스트로 남긴다.
