# GitHub Copilot FAQ 요약

- 원문: https://code.visualstudio.com/docs/agents/agent-troubleshooting/faq
- 문서 제목: GitHub Copilot frequently asked questions
- 원문 수정일: 2026-08-19

## 플랜과 계정

Copilot Free, 유료 플랜, Business·Enterprise 구독으로 VS Code AI 기능을 사용한다. 월별 inline suggestions와 AI credits 한도는 서로 다르고 매월 초기화된다.

VS Code에 로그인한 GitHub 계정이 실제 Copilot 구독 계정인지 확인한다. 다른 계정을 사용했다면 로그아웃 후 올바른 계정으로 전환한다.

## AI 기능 문제

`chat.disableAIFeatures`는 Chat과 inline suggestions 같은 내장 AI 기능을 숨길 수 있다. 연결 문제는 VS Code·확장 업데이트, 구독 상태, 네트워크·방화벽·프록시·VPN을 확인한다.

Inline suggestions가 작동하지 않으면 `github.copilot.enable`, NES 설정, 구독, 네트워크, 월간 한도를 점검한다. Agent가 보이지 않으면 `chat.agent.enabled`와 조직 정책을 확인한다.

## 코드베이스와 정책

대규모 저장소와 monorepo는 semantic indexing, LSP, GitHub code search, custom instructions로 지원한다. 모델 접근, Agent, content exclusion과 같은 기능은 조직 관리자 정책으로 제한될 수 있다.

## 핵심 요약

Copilot 문제를 해결할 때 계정·플랜, AI credit과 inline 한도, 확장·네트워크, Agent 설정, 조직 정책을 분리해 확인한다. 대규모 코드베이스는 인덱싱과 프로젝트 지침을 함께 구성해야 한다.
