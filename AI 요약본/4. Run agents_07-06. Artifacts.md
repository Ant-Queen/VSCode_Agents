# Artifacts 요약

- 원문: https://code.visualstudio.com/docs/agents/run/artifacts
- 문서 제목: Use artifacts in agent sessions
- 원문 수정일: 2026-10-07

## 아티팩트와 참조

Artifacts panel은 에이전트 작업에서 중요한 결과물과 참고 자료를 채팅 옆에 모아 보여준다. 파일·스크린샷·계획뿐 아니라 GitHub 이슈와 PR도 표시될 수 있다. 세션이 실제 작업하는 대상은 artifact, 단순히 정보로 살펴보는 대상은 reference로 구분한다.

기능은 Preview이며 `chat.artifacts.enabled`를 켜야 한다. Chat view와 Agents window에서 사용할 수 있다.

## 표시되는 출처

- **규칙 기반 추출**: 도구 결과의 MIME 유형, 작업 공간 파일 경로, memory 파일 경로에 맞는 항목을 자동 표시한다.
- **에이전트 지정**: `#artifacts` 도구로 에이전트가 지정한 목록을 표시한다. 업데이트는 이전 agent 목록을 대체한다.
- **서브에이전트 지정**: 서브에이전트별 결과를 이름이 붙은 그룹으로 분리한다.

설정 `chat.artifacts.rules.byMimeType`, `chat.artifacts.rules.byFilePath`, `chat.artifacts.rules.byMemoryFilePath`에 패턴과 그룹 이름을 정의할 수 있다. 예를 들어 `**/*plan*.md`를 Plans 그룹으로 지정하거나 `image/*`를 Screenshots로 분류할 수 있다. 규칙 기반 추출을 끄려면 세 설정을 모두 `{}`로 둔다.

## 사용과 제거

아티팩트를 선택하면 이미지 미리보기나 해당 문서가 열린다. 대화 내용과 설정 규칙에 따라 자동 추출 결과가 갱신된다. 자연어로 앱 스크린샷, 프로젝트 계획, 링크를 artifact로 저장해 달라고 요청할 수 있다. 현재 세션만 추출 규칙을 바꾸려면 `#artifactRules` 도구를 사용한다.

항목을 제거해도 실제 파일·웹사이트·이슈·PR이 삭제되거나 변경 사항이 되돌려지는 것은 아니다. 기록된 항목 중 안정적인 ID가 있고 provider가 제거를 지원하는 경우에만 제거할 수 있으며, 독립적으로 발견된 항목은 다시 표시될 수 있다.

## 핵심 요약

Artifacts panel은 중요한 결과물과 참조를 출처별로 모아 재방문하기 쉽게 한다. 표시 제거는 세션 내 기록만 바꾸며 원본 파일이나 외부 리소스의 변경·삭제와는 무관하다.
