# Inline Chat and Quick Chat 요약

- 원문: https://code.visualstudio.com/docs/chat/inline-chat
- 문서 제목: Inline chat and Quick Chat
- 원문 수정일: 2026-08-19

## Inline Chat

Inline Chat은 현재 편집기의 코드와 선택 영역에 초점을 맞춘 빠른 질문·수정 기능이다. 편집기에서 `Ctrl+I`를 누르고 요청을 입력하면 변경 diff가 표시되며 Keep 또는 Undo로 반영한다.

활성 Chat editing 세션의 파일에서는 기존 Chat session의 Ask in Chat으로 연결될 수 있다. 일반 Inline Chat을 강제하려면 `inlineChat.askInChat`을 `false`로 설정한다.

선택 영역의 시각적 affordance는 `inlineChat.affordance`로 끄거나 gutter·editor 방식으로 설정한다.

## Terminal Inline Chat

터미널 Inline Chat은 명령 제안에 특화된다. 제안된 명령을 `Ctrl+Enter`로 실행하거나 `Alt+Enter`로 터미널에 삽입한 뒤 직접 검토할 수 있다.

## 모델 설정

`inlineChat.defaultModel`로 기본 Inline Chat 모델을 지정한다. 세션 중 모델을 바꾸면 해당 세션 동안 유지되고, VS Code를 다시 시작하면 설정된 기본 모델로 돌아간다.

## Quick Chat

Quick Chat은 `Ctrl+Shift+Alt+L`로 여는 가벼운 대화 표면이다. 작업 공간에 연결되지 않은 질문이나 짧은 작업에 사용하며, `#`과 `@` mention을 지원한다.

필요하면 Quick Chat에서 전체 Chat view로 대화를 이어갈 수 있다. 여러 파일을 수정하거나 테스트·도구 호출이 필요한 작업은 Chat view나 Agents window를 사용하는 것이 적합하다.

## 핵심 요약

Inline Chat은 현재 코드 위치의 국소 변경을 diff로 검토하는 도구이고, Terminal Inline Chat은 명령 제안 도구다. Quick Chat은 빠른 일반 질문에 적합하며, 복잡한 작업은 전체 Chat 표면으로 확장한다.
