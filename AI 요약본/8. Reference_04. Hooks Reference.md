# Hooks Reference 요약

- 원문: https://code.visualstudio.com/docs/agents/reference/hooks-reference
- 문서 제목: Hooks reference
- 원문 수정일: 2026-08-19

## 공통 명령 속성

Hook 항목은 `type: "command"`와 `command`가 필수다. `windows`, `linux`, `osx`, `cwd`, `env`, `timeout`으로 운영체제별 명령, 작업 디렉터리, 환경 변수, 제한 시간을 설정한다.

## 이벤트별 동작

- **PreToolUse**: 도구명·입력·tool use id를 받고 실행 전 승인 결정, 입력 수정, 추가 컨텍스트를 반환한다.
- **PostToolUse**: 성공한 도구 실행 후 컨텍스트를 추가하거나 후속 처리를 block한다.
- **SessionStart**: 세션 시작 정보와 `additionalContext`를 주입한다.
- **UserPromptSubmit**: 사용자 요청 제출 시 공통 결과 형식을 사용한다.
- **PreCompact**: 대화 압축 전 처리한다.
- **Stop/SubagentStop**: 종료를 막고 추가 실행을 요청할 수 있다.

## 승인 결정

PreToolUse의 결정은 `allow`, `deny`, `ask`로 지정한다. 여러 hook이 결과를 반환하면 `deny`가 `ask`보다, `ask`가 `allow`보다 우선해 가장 제한적인 결정이 적용된다.

`updatedInput`으로 도구 입력을 안전한 값으로 바꾸고, `permissionDecisionReason`으로 사용자에게 이유를 설명할 수 있다.

## 반복 방지와 안전

Stop 또는 SubagentStop에서 block할 때는 입력의 `stop_hook_active`를 확인해 무한 반복을 막는다. Hook은 외부 명령을 실행하므로 script 경로, 환경 변수, timeout과 출력 JSON을 검증한다.

## 핵심 요약

Hooks reference는 hook 명령의 속성과 이벤트별 입력·출력 계약을 정의한다. PreToolUse로 위험 작업을 차단하고 PostToolUse·SessionStart로 검증과 컨텍스트를 추가할 수 있지만, 결정 우선순위와 반복 방지 조건을 정확히 구현해야 한다.
