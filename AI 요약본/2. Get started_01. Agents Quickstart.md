# Agents Quickstart 요약

- 원문: https://code.visualstudio.com/docs/agents/quickstart
- 문서 제목: Quickstart: Complete your first task with an agent
- 원문 수정일: 2026-08-19

## 학습 목표

자연어 프롬프트로 간단한 웹 앱을 만들고, 생성된 코드를 검토한 뒤 브라우저 도구로 기능을 검증하는 과정을 익힌다. Agents window와 Chat view 중 어느 쪽에서 시작해도 같은 앱과 세션을 사용할 수 있다.

## 사전 준비

- Visual Studio Code 설치
- VS Code에서 AI 기능 설정
- GitHub Copilot 또는 사용할 AI 모델 설정

## 프로젝트 폴더 만들기

터미널에서 다음 명령으로 예제 프로젝트 폴더를 만든다.

```bash
mkdir agent-quickstart
```

이 폴더를 VS Code에서 작업 공간으로 연다.

## 에이전트로 앱 만들기

1. VS Code 제목 표시줄에서 **Open in Agents**를 선택하거나 명령 팔레트에서 `Chat: Open Agents Window`를 실행한다.
2. Agents window 왼쪽 사이드바 상단의 **New**를 선택한다.
3. Local 탭에서 `agent-quickstart` 폴더를 작업 공간으로 선택한다. 신뢰 여부를 묻는 경우 폴더를 신뢰한다.
4. **Copilot** 에이전트 하니스와 **Agent** 역할을 선택한다. 도구 실행 전에 확인하려면 **Manual Permissions**를 유지한다.
5. 다음 프롬프트를 입력한다.

```text
Create a task list web app in a single index.html file with embedded CSS and JavaScript. Let me add, complete, and delete tasks. Save the tasks in local storage so they persist after a page reload. Use no external libraries.
```

에이전트는 작업을 해석하고 `index.html`을 생성하며, 진행 중 필요한 작업에 대해 승인이나 추가 정보를 요청할 수 있다.

## 결과 검토 및 검증

생성된 코드는 반드시 검토한다. Changes 패널에서 `index.html`을 열어 변경 내용을 확인하고, 문제가 있으면 diff에서 해당 부분을 선택해 에이전트에게 피드백을 보낸다.

다음 프롬프트로 통합 브라우저에서 핵심 사용 흐름을 검증한다.

```text
Open index.html in the integrated browser and validate the app.
Add a task, mark it complete, and delete it. Then add another task,
reload the page, and verify that the task persists. If any step fails,
fix the issue and repeat the complete flow.
```

검증할 시나리오는 작업 추가, 완료 표시, 삭제, 새 작업 추가, 새로 고침 후 `localStorage`를 통한 작업 유지다. 에이전트가 브라우저 도구로 검증하고 오류를 수정했더라도 최종 결과를 직접 확인한다.

## Agents window와 Chat view 전환

두 인터페이스는 같은 에이전트 세션을 공유한다.

- Agents window에서 **Open in Editor**를 선택하면 편집기와 Chat view에서 같은 세션을 계속 사용할 수 있다.
- Chat view에서 **Open in Agents**를 선택하면 Agents window에서 같은 세션을 열 수 있다.

## 정리 및 다음 단계

실습이 끝나면 VS Code에서 `agent-quickstart` 폴더를 닫고 컴퓨터에서 해당 폴더를 삭제할 수 있다. 이후 [Agents Tutorial](https://code.visualstudio.com/docs/agents/agents-tutorial)에서 더 큰 앱을 만들고, [Browser Tools](https://code.visualstudio.com/docs/agents/run/browser-tools) 사용법을 학습한다.

## 핵심 요약

Quickstart의 핵심은 자연어로 목표를 설명하고, 에이전트가 코드를 작성하도록 한 뒤, 사용자가 승인과 코드 리뷰를 통해 통제하면서 브라우저에서 실제 동작을 검증하는 것이다.
