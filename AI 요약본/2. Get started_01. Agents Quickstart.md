# Agents Quickstart 요약

- 원문: https://code.visualstudio.com/docs/agents/quickstart
- 문서 제목: Quickstart: Complete your first task with an agent
- 원문 수정일: 2026-09-16

## 문서 핵심

이 문서는 VS Code에서 에이전트를 처음 사용하는 사람을 위한 실습 가이드다. 가장 단순한 형태로 Chat view를 열고, 자연어 프롬프트로 작은 웹 앱을 생성한 뒤, 브라우저에서 동작을 검증하고 결과를 리뷰하는 흐름을 보여준다.

## 1. 사전 준비

- VS Code 설치
- GitHub Copilot 설정 완료
- 작업용 빈 폴더 생성
- 에이전트가 작업할 프로젝트 폴더는 기존 코드가 아닌 비어 있는 폴더를 권장

중요: 기존 프로젝트에 에이전트를 붙이기 전에 보안 기준을 확인하는 것이 좋다.

## 2. 프로젝트 폴더 생성

예시로 `agent-quickstart` 폴더를 만든다. 이후 VS Code에서 해당 폴더를 열어 작업한다.

- 폴더를 신뢰할지 여부를 묻는 경고가 나오면 Trust 선택
- Chat view를 열고 새 채팅 시작
- Copilot 세션 타깃과 Agent 역할 선택
- Manual permissions 유지
- 필요한 경우 모델을 Auto로 설정

## 3. 첫 번째 에이전트 작업

다음과 같은 프롬프트를 입력한다.

```text
Create a task list web app in a single index.html file with embedded CSS and JavaScript. Let me add, complete, and delete tasks. Save the tasks in local storage so they persist after a page reload. Use no external libraries.
```

이 프롬프트에 따라 에이전트는 `index.html` 파일을 생성하고, 필요한 UI와 자바스크립트 로직을 자동으로 구성한다.

## 4. 승인과 검토

에이전트는 파일 수정, 브라우저 실행, 터미널 작업 등에서 승인 요청을 보낼 수 있다. 이 단계에서는 각 요청을 검토한 뒤 승인하는 방식으로 진행한다.

- 파일 수정은 기본적으로 콘텍스트에 따라 자동 반영될 수 있음
- 민감하거나 예기치 못한 동작은 별도 승인 필요
- 결과를 반드시 diff로 점검해야 함

## 5. 브라우저로 검증

에이전트에게 다음과 같은 프롬프트로 검증을 요청한다.

```text
Open index.html in the integrated browser and validate the app.
Add a task, mark it complete, and delete it. Then add another task,
reload the page, and verify that the task persists. If any step fails,
fix the issue and repeat the complete flow.
```

이렇게 하면 에이전트가 브라우저를 열고 실제 사용 흐름을 테스트한다.

## 6. 직접 확인

에이전트가 수행한 검증은 보조 수단일 뿐, 최종 확인은 사용자가 해야 한다.

사용자가 직접 확인해야 할 항목:

- 할 일 추가
- 완료 표시
- 페이지 새로고침 후 상태 유지
- 삭제 후 재로딩에서도 유지되지 않음

실패가 확인되면 채팅으로 문제를 설명하고 에이전트에게 수정 및 재검증을 요청한다.

## 7. 중단, 수정, 복구

작업 중에 다음을 할 수 있다.

- 요청 즉시 수정 또는 중지
- 결과를 다시 지시하여 수정
- 특정 시점으로 복원 (Restore Checkpoint)

단, 중지 자체는 이미 완료된 작업을 되돌리지는 못한다.

## 8. 다른 인터페이스 사용

에이전트 창(Agents window)에서도 동일한 작업을 수행할 수 있다. Chat view와 Agents window는 같은 세션을 공유한다.

## 9. 정리

실습이 끝나면 로컬 리소스를 정리한다.

- `agent-quickstart` 폴더 닫기
- 로컬 폴더 삭제

## 핵심 요약

에이전트 퀵스타트는 “자연어로 목표를 설명하고, 에이전트가 코드를 작성하고, 브라우저에서 동작을 검증한 뒤, 사용자가 최종 확인하는” 흐름을 가장 단순하게 보여준다. 이 과정을 통해 VS Code에서 AI 에이전트를 실습적으로 이해할 수 있다.
