# Context 개념 요약

- 원문: https://code.visualstudio.com/docs/agents/concepts/context
- 문서 제목: Understand context in AI agents
- 원문 수정일: 2026-09-16

## 핵심 개념

컨텍스트는 에이전트와 모델이 작업을 수행할 때 사용할 수 있는 정보 전체를 의미한다. 여기에는 대화 기록, 작업 중인 파일, 코드베이스 내용, 도구 출력, 커스텀 지침, 사용자가 명시적으로 붙인 참조 등이 포함된다.

좋은 컨텍스트는 좋은 결과를 만든다. 반대로 불필요하거나 너무 많은 정보는 비용과 혼란을 증가시킨다.

## 1. 왜 컨텍스트가 중요한가

모델은 현재 포함된 정보만을 근거로 판단한다. 그래서 작업 목표가 분명해도 관련 파일, 오류, 기존 패턴이 빠지면 결과가 추상적이거나 틀릴 수 있다.

예를 들어 “인증이 어떻게 동작하나?”라는 질문을 할 때, 관련 파일을 함께 참조하면 훨씬 정확하게 설명할 수 있다.

## 2. VS Code가 컨텍스트를 조립하는 방식

VS Code는 매 요청마다 다음 요소를 조합해 모델에 전달한다.

- 시스템 지침
- 커스터마이징
- 사용자 메시지
- 대화 이력
- 암시적 컨텍스트
- 명시적 참조
- 도구 출력

즉, 에이전트는 단순히 현재 프롬프트만 본 것이 아니라, 작업과 관련된 모든 정보를 점점 쌓아가며 다음 행동을 결정한다.

## 3. 암시적 컨텍스트

VS Code는 현재 작업 환경을 자동으로 반영한다.

- 현재 활성 에디터의 선택 텍스트
- 활성 파일 이름
- 현재 오류 상태
- Git 상태
- 작업 중인 파일

이런 정보는 자동으로 전달되므로, 사용자가 모든 내용을 다시 적지 않아도 된다. 다만 정말 중요한 파일은 직접 참조해 주는 것이 더 좋다.

## 4. 명시적 컨텍스트

명시적 컨텍스트는 `#`로 참조하는 방식이다. 예를 들어 특정 파일, 심볼, 터미널 결과, 웹 페이지, 이미지 등을 보조 정보로 첨부할 수 있다.

이 방식은 다음에 유용하다.

- 해당 파일이 반드시 포함되어야 할 때
- 특정 심볼을 기준으로 분석해야 할 때
- 브라우저/터미널 결과를 참고해야 할 때

다만 너무 많은 참조는 context window를 소모하므로, 필요한 소스만 첨부하는 것이 좋다.

## 5. 워크스페이스 인덱싱

VS Code는 semantic index를 사용해 키워드 기반이 아닌 의미 기반으로 코드를 검색한다.

- 파일 이름이나 키워드가 아니라 “의미”에 기반해 관련 코드 찾기
- 큰 코드베이스에서도 빠른 탐색 가능
- 검색 범위는 프로젝트에 따라 다름

전체 코드베이스를 매번 붙이는 대신, 인덱싱을 통해 필요한 코드만 찾도록 돕는다.

## 6. Context Window와 compaction

모델은 한 번에 처리할 수 있는 컨텍스트의 양이 제한되어 있다. 이를 context window라고 한다.

이 한계에 가까워지면 VS Code는 오래된 대화를 요약해서 새 정보를 넣을 수 있게 한다. 이것을 compaction이라고 한다.

권장 사항:

- 관련 없는 작업은 새 세션으로 분리
- 프로젝트 지침은 대화 이력이 아니라 custom instructions에 저장
- 오래된 불필요한 대화는 정리

## 7. Subagent와 Context Isolation

복잡한 작업은 메인 에이전트가 하위 에이전트(subagent)에 맡길 수 있다. 이때 하위 에이전트는 별도의 컨텍스트를 갖고 작업한다.

장점:

- 메인 대화의 혼란을 줄임
- 중간 결과를 별도로 처리 가능
- 핵심 추적 정보를 유지하면서 복잡한 분석을 분리 가능

## 8. 효과적인 컨텍스트 사용법

개발자가 따라야 할 기본 원칙은 다음과 같다.

- 목표와 제약 조건을 명확히 설명
- 에이전트가 필요한 컨텍스트를 스스로 찾도록 허용하되, 핵심 파일은 직접 연결
- 관련 소스만 참조
- 서로 다른 작업은 새 세션으로 분리

## 9. 요약

컨텍스트는 에이전트의 성능을 좌우하는 핵심 요소다. VS Code는 자동으로 관련 정보를 수집하고, 사용자는 파일/심볼/터미널 결과를 명시적으로 제공함으로써 더 정확한 결과를 얻을 수 있다. 단, 토큰 제한과 비용을 고려해 필요한 정보만 정제해서 제공하는 것이 중요하다.
