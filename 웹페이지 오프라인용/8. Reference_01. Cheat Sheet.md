# AI Features Cheat Sheet 요약

- 원문: https://code.visualstudio.com/docs/agents/reference/ai-features-cheat-sheet
- 문서 제목: AI features in VS Code cheat sheet
- 원문 수정일: 2026-08-19

## 주요 기능

- Agent: 여러 파일 수정, 터미널·도구 호출, 반복 작업
- Chat: 질문, 탐색, 계획과 구현
- Inline suggestions: 코드 자동 완성
- Inline Chat: 현재 코드의 국소 수정
- Smart actions: 커밋 메시지, 오류 수정, 심볼 변경
- MCP와 확장 도구: 외부 시스템 연결
- Custom instructions, prompt files, custom agents: AI 동작 맞춤화

## 주요 단축키

- Chat view: `Ctrl+Alt+I`
- Inline Chat: `Ctrl+I`
- 새 세션: `Ctrl+N`
- 모델 선택: `Ctrl+Alt+.`

## 컨텍스트와 명령

`#` mention, `/` slash command, `@` participant, Add Context, drag-and-drop으로 파일·폴더·심볼·도구·터미널 결과를 프롬프트에 추가한다. `/plan`, `/debug`, `/troubleshoot`, `/compact`, `/fork`, `/newNotebook` 등이 대표 명령이다.

## 도구와 작업

Agent, Browser, Edit, Execute, Read, GitHub, Web 도구를 작업에 맞게 선택한다. MCP와 확장으로 도구를 확장할 수 있다. 생성된 코드·테스트·디버깅·Source Control 변경을 검토한다.

`chat.math.enabled`와 `mermaid-chat.enabled`로 수식과 Mermaid 렌더링을 설정할 수 있다.

## 핵심 요약

Cheat sheet는 VS Code AI 기능과 단축키, context 추가 방식, slash command, 도구 유형을 빠르게 찾는 참조표다. 질문·국소 편집·다중 파일 작업을 기능 목적에 맞게 구분하면 효율이 높아진다.
