# Chat View 요약

- 원문: https://code.visualstudio.com/docs/agents/run/chat-view

- 원문 수정일: 2026-08-19

## Chat view란

Chat view는 현재 프로젝트의 코드 옆에서 에이전트와 작업하는 VS Code 기본 인터페이스다. 편집기 탭과 함께 표시되므로 프롬프트를 보내고, 변경 사항을 검토하고, 테스트와 디버깅을 수행하면서 작업 공간을 떠나지 않을 수 있다.

다음과 같은 code-first 작업에 적합하다.

- 편집기에서 변경 파일의 diff를 검토하고 수정 요청하기
- 디버거, Tasks, 테스트로 에이전트 변경을 검증하기
- 설치된 확장과 노트북을 사용하기
- 원격 작업 공간에서 같은 컨텍스트와 도구로 작업하기

Chat view와 agent-first 방식의 Agents window는 같은 세션과 설정을 공유한다.

## 열기와 레이아웃

- 제목 표시줄의 Chat 메뉴에서 **Open Chat** 선택
- `Ctrl+Alt+I` 단축키 사용
- 명령줄에서 `code chat` 실행

새 채팅은 다음 레이아웃으로 열 수 있다.

- **Side bar**: 코드 옆에 채팅을 유지한다.
- **Editor tab**: 넓은 영역에서 채팅을 보거나 세션을 나란히 비교한다.
- **Separate window**: 여러 모니터에서 사용한다.

## 화면 구성

- **Sessions list**: 현재 작업 공간의 세션을 관리한다.
- **Chat conversation**: 대화와 에이전트 응답, 코드 변경을 확인한다.
- **Chat input**: 프롬프트와 하니스, 에이전트, 모델, 권한을 설정한다.

Chat view는 compact와 side-by-side 모드를 지원한다. Compact에서는 세션 목록과 대화가 같은 패널에 표시되고, side-by-side에서는 세션 목록이 대화 옆에 계속 표시된다.

## 세션 시작

1. **New Chat** 또는 `Ctrl+N`을 선택한다.
2. Chat input에서 agent target, agent, language model, permission level을 설정한다.
3. 프롬프트를 입력하고 Enter를 누른다.

에이전트는 요청을 단계로 나누고, 파일을 편집하고, 명령을 실행하며, 문제가 있으면 스스로 수정한다. 세션 중에도 하니스와 기타 설정을 변경할 수 있다.

## 에이전트 작업 확인

에이전트가 직접 수정한 파일은 응답의 변경 파일이나 Source Control에서 diff로 확인한다. `chat.checkpoints.showFileChanges`를 활성화하면 요청별 변경 파일 요약을 볼 수 있다.

터미널 명령의 출력은 실시간으로 확인할 수 있다. 변경 후에는 VS Code 디버거, Tasks, 테스트를 실행해 결과를 검증한 뒤 커밋한다. 설치된 확장과 Jupyter notebook도 편집기에서 에이전트와 함께 사용할 수 있다.

## 핵심 요약

Chat view는 코드와 채팅을 한 화면에서 연결하는 작업 공간이다. 단일 프로젝트의 구현·리뷰·테스트·디버깅을 반복해야 할 때 적합하며, 필요하면 같은 세션을 Agents window에서 계속할 수 있다.
