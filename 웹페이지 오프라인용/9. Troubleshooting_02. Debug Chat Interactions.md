# Debug Chat Interactions 요약

- 원문 수정일: 2026-08-19

## Agent Debug Logs

Agent Debug Logs는 Preview 기능으로 Logs, Agent Flow Chart, Summary, Cache Explorer를 제공한다. Logs에서는 이벤트를 flat 또는 tree로 보고 도구 호출, LLM 요청, 오류를 필터링한다.

Summary에는 도구 호출 수, 토큰 사용량, 오류 수, 총 소요 시간이 표시된다. Flow Chart는 주 에이전트와 서브에이전트의 실행 관계를 시각화한다.

## 분석과 공유

debug event snapshot을 Chat에 첨부하거나 `/troubleshoot #session`으로 분석을 요청할 수 있다. 세션은 OTLP JSON으로 export·import할 수 있으며 50MB 초과 파일에는 경고가 표시된다.

Chat Debug view에서는 system prompt, user prompt, context, response, tool response를 펼쳐 확인한다.

## 문제별 점검

- 파일이 포함되지 않음: context discovery를 확인한다.
- 도구가 호출되지 않음: 활성 도구와 도구 선택을 확인한다.
- 응답이 잘림: token과 context window를 확인한다.
- prompt가 적용되지 않음: instructions·skill·prompt file 발견 로그를 확인한다.

## 핵심 요약

Debug Chat view는 결과만 보는 대신 실제 prompt, 컨텍스트, 도구 호출과 비용을 추적하게 한다. Logs에서 흐름을 확인하고 Summary·Flow Chart·Cache Explorer로 성능과 누락 원인을 단계적으로 분석한다.
