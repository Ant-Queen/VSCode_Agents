- 원문 수정일: 2026-08-19

## 모델과 작업 선택

간단한 편집과 보일러플레이트에는 빠르고 저렴한 모델을, 설계·디버깅·복잡한 리팩터링에는 reasoning 모델을 사용한다. Auto model selection이나 Custom agent별 모델 지정으로 품질과 비용의 균형을 맞춘다.

## 컨텍스트와 세션 절약

- 구현 전에 Plan agent로 계획해 폐기 작업을 줄인다.
- 주제가 바뀌면 새 세션을 연다.
- 대안 탐색은 `/fork`로 분리한다.
- `/compact`로 오래된 대화를 요약한다.
- 필요한 파일과 도구만 context에 포함한다.
- `.gitignore`, `files.exclude`, `search.exclude`로 큰 생성물과 잡음을 제외한다.

Thinking effort는 복잡한 요청에만 높이고, 도구·MCP 서버도 필요한 것만 활성화한다.

## 사용량 측정

단일 응답 비용은 Chat 응답 hover에서, 세션 누적 비용과 토큰은 context window control에서, 월간 사용량은 Copilot status dashboard에서 확인한다.

Agent Debug Logs의 Summary와 Cache Explorer로 도구 호출, 토큰 사용, prompt cache hit rate와 재사용 토큰을 분석한다. 안정적인 prompt prefix는 캐시 재사용에 유리하다.

## 핵심 요약

AI credit은 모델·thinking effort·컨텍스트·도구 호출량의 영향을 받는다. 계획과 세션 분리로 재작업을 줄이고, 관련 컨텍스트만 사용하며, 사용량과 캐시를 측정해 작업 방식과 모델을 조정해야 한다.
