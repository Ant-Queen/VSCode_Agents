# Agent Host Architecture 요약

- 원문: https://code.visualstudio.com/docs/agents/concepts/agent-host
- 문서 제목: VS Code Agent Host architecture
- 원문 수정일: 2026-08-19

## Agent Host란

VS Code는 **Agent Host**라는 전용 프로세스에서 AI 코딩 에이전트를 실행한다. VS Code 클라이언트는 Agent Host와 **Agent Host Protocol(AHP)**을 통해 통신한다.

Agent Host가 세션을 화면을 표시하는 클라이언트와 독립적으로 소유하므로, 여러 클라이언트가 같은 세션을 관찰·제어할 수 있고 창을 닫아도 작업이 계속될 수 있다.

## 전용 프로세스의 이점

- 여러 클라이언트에서 세션을 공유한다.
- 작업 공간 가까운 원격 컴퓨터에서 실행할 수 있다.
- 편집기나 다른 클라이언트가 연결되지 않아도 세션이 계속된다.
- 여러 에이전트 구현을 하나의 공통 인터페이스에 연결한다.
- 바쁜 확장으로 인해 장시간 자율 작업이 차단되지 않는다.

기존 확장 호스트 세션도 유지된다. 확장은 도구, MCP 서버, Custom agent 같은 채팅 맞춤화를 제공할 수 있지만, Agent Host 세션의 에이전트 런타임은 별도 프로세스에서 실행된다.

## 프로세스 구조

Agent Host는 로컬 유틸리티 프로세스 또는 원격 독립 서버로 실행된다. 로컬 통신에는 message port를 사용하고, 원격 연결에는 WebSocket 기반 AHP JSON-RPC를 사용한다.

일방적인 에이전트 어댑터는 Agent Host 안에서 실행되며, 각 공급자 런타임과 공통 AHP 세션 모델 사이를 변환한다. Agent Host는 작업 공간 가까이 위치하므로 원격 실행 시 파일 편집과 명령 실행도 원격 컴퓨터에서 일어난다.

## Agent Host Protocol

AHP는 호스트와 클라이언트 사이의 에이전트 중립적 프로토콜이다. JSON-RPC와 변경 불가능한 상태, 순수 reducer를 사용해 세션 데이터를 동기화한다.

호스트가 상태의 진실 공급원이며, 클라이언트는 세션·채팅·터미널·changeset 같은 URI 주소 리소스 채널을 구독한다. 클라이언트는 초기 상태 스냅샷과 순서가 보장된 action을 받고, 연결이 끊기면 누락된 action이나 새 스냅샷을 받아 재연결한다.

## 클라이언트 도구

Agent Host는 클라이언트 없이도 세션을 관리하고 작업 공간에서 일할 수 있는 기본 기능을 가진다. 연결된 클라이언트는 통합 브라우저나 설치된 확장 도구를 추가로 제공할 수 있으며, Agent Host는 해당 도구 호출을 제공한 클라이언트로 라우팅한다.

## 로컬·원격 호스트

원격 세션에서는 독립 Agent Host가 WebSocket으로 AHP를 노출하고, Agents window가 SSH 또는 개발 터널로 연결한다. 직접 실행하려면 `code agent host` 명령을 사용할 수 있으며, 기본적으로 localhost에서 연결 토큰으로 보호된 서버가 시작된다. `--tunnel` 옵션은 개발 터널을 사용한다.

## 확장 호스트 세션과의 차이

Agent Host 세션은 변경 사항이 세션 폴더나 worktree에 직접 적용되고 diff로 검토한다. 확장 호스트 세션은 변경 사항을 pending 상태로 추적하며 Keep 또는 Undo로 확정한다.

Agent Host에서만 여러 창 세션, 여러 채팅, Quick Chat, 원격 호스팅, Assisted permissions를 사용할 수 있다. 확장 도구는 해당 확장이 실행 중인 편집기 창의 채팅에서만 제공된다.

Agent Host는 `.mcp.json`과 `~/.copilot/mcp-config.json`을 읽는다. VS Code 설정의 `.vscode/mcp.json`은 대화형 입력이 필요한 서버를 제외하고 Agent Host로 전달될 수 있다.

## 핵심 요약

Agent Host는 에이전트 세션을 클라이언트와 분리해 공유·원격·백그라운드 실행을 가능하게 한다. AHP가 상태 동기화의 공통 기반을 제공하고, 클라이언트는 필요에 따라 브라우저와 확장 도구를 추가한다.
