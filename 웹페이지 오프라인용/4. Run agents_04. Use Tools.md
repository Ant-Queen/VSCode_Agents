# Use Tools 요약

- 원문: https://code.visualstudio.com/docs/agents/run/tools
- 문서 제목: Use tools with agents
- 원문 수정일: 2026-08-19

## 도구 선택

도구는 코드 검색, 명령 실행, 웹 콘텐츠 조회, API 호출 등 특정 작업을 에이전트에 제공한다. VS Code는 Built-in, MCP, Extension 도구를 지원한다.

Chat view에서 Agent를 선택한 뒤 **Configure Tools**를 열어 현재 요청에 사용할 도구를 선택하거나 해제한다. MCP 서버를 추가하거나 도구를 제공하는 확장을 설치하면 목록에 추가된다. Copilot 하니스는 채팅별 선택이 아니라 프로필 범위의 Tools 맞춤화에서 관리한다.

작업에 관련된 도구만 선택하면 불필요한 도구 호출과 컨텍스트 사용을 줄이고 결과의 관련성을 높일 수 있다.

## 프롬프트에서 도구 사용

에이전트는 프롬프트와 컨텍스트를 보고 필요한 도구를 자동으로 선택한다. 특정 도구를 강제하려면 `#` 뒤에 도구 이름을 입력한다.

예시:

- `What is the latest version of Node.js #web`
- `How does routing work in Next.js? #web`
- `Fix the issues in #problems`
- `Explain the authentication flow #codebase`

도구 목록과 MCP 도구, 확장 도구, 도구 세트는 채팅 입력창에 `#`을 입력해 확인할 수 있다. Prompt file과 Custom agent에는 작업별 도구 목록을 지정할 수 있다.

## 브라우저 도구

내장 브라우저 도구를 사용하면 에이전트가 앱을 실행하고, 통합 브라우저에서 페이지를 열고, 사용자 흐름을 수행하고, 콘텐츠·스크린샷·콘솔 오류를 분석하고, 문제를 수정한 뒤 다시 검증할 수 있다. 외부 MCP 서버가 필요하지 않다.

예를 들어 앱을 시작하고 비밀번호 재설정 흐름을 테스트한 뒤 발견한 문제를 수정하고 전체 흐름을 재검증하도록 요청할 수 있다.

## 도구 매개변수 검토

도구 승인 대화 상자에서 도구 이름 옆의 펼침 화살표를 선택하면 입력 매개변수를 확인하고 수정할 수 있다. 수정한 뒤 Allow를 선택해 실행한다.

## 터미널 명령

에이전트는 통합 터미널에서 하나의 terminal 도구로 명령을 실행한다. 채팅의 명령 옆 **Show Output**에서 결과를 확인하거나 **Show Terminal**로 전체 터미널을 열 수 있다.

장시간 서버나 watch 명령은 **Continue in Background**로 백그라운드에 보내고, 에이전트가 나중에 출력을 확인하게 할 수 있다. `chat.tools.terminal.outputLocation`으로 출력 위치를 설정할 수 있으며, timeout 설정과 강제 여부도 조정할 수 있다.

Windows에서는 PowerShell, macOS·Linux에서는 bash/zsh처럼 shell integration이 지원되는 셸을 사용하는 것이 좋다. Windows의 cmd와 macOS/Linux의 sh는 상태 신호를 얻기 어려워 느리고 불안정할 수 있다.

## 제한과 직접 제작

요청 하나에 활성화할 수 있는 도구는 최대 128개다. 초과하면 Tools picker에서 도구나 MCP 서버를 줄이거나 `github.copilot.chat.virtualTools.threshold`를 사용한다.

직접 도구를 만들려면 Language Model Tools API를 사용하는 VS Code 확장을 개발하거나, 도구를 제공하는 MCP 서버를 만든다.

## 핵심 요약

도구는 에이전트가 실제 개발 환경에서 행동하게 하는 실행 수단이다. 요청에 필요한 도구만 활성화하고, 중요한 매개변수와 터미널 출력은 검토하며, 장시간 명령은 백그라운드 실행으로 관리해야 한다.
