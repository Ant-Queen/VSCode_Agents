# Automations 요약

- 원문: https://code.visualstudio.com/docs/agents/run/automations
- 문서 제목: Create and manage agent automations
- 원문 수정일: 2026-10-07

## 자동화의 용도와 준비

Automations는 저장된 프롬프트, 세션 설정, 스케줄로 반복 에이전트 작업을 실행한다. 저장소 변경 요약이나 이슈 분류처럼 정기적으로 수행하는 작업에 활용할 수 있다. Agents window와 사용할 수 있는 에이전트가 필요하며 `chat.automations.enabled`를 켜야 한다. 기능은 Preview 단계이고 Stable에서는 기본적으로 꺼져 있다.

## 만들고 시험하기

Agents window의 Automations에서 Create Automation 또는 템플릿을 선택한다. 이름과 프롬프트에 범위·원하는 출력을 명시하고, 작업 공간 또는 No workspace, agent, 모델, 권한, 격리 방식을 설정한다. 처음에는 Schedule을 Manual로 두고 Run now로 실행한 뒤 History에서 결과와 변경 사항을 검토한다.

자동화는 설정된 권한에 따라 파일을 읽고 명령을 실행하거나 수정할 수 있다. 예약 실행 전에 권한과 격리 설정을 확인해야 하며, 저장만으로 승인 절차나 조직 정책을 우회하지 않는다.

## 스케줄과 실행 조건

Manual은 직접 실행할 때만 작동하고, Hourly·Daily·Weekly는 반복 실행한다. 일·주간 시간은 로컬 시간대를 따른다. 예약 실행에는 Agent Host 또는 VS Code가 실행되는 머신과 사용 가능한 에이전트가 필요하다. 종료 중 놓친 실행은 재개 시 따라잡기 실행될 수 있지만, 누락분 전체가 반드시 재생되는 것은 아니다. 하나의 자동화는 동시에 여러 번 실행하지 않는다.

## 공유와 관리

`.automation.md`로 내보내고 가져와 자동화를 재사용할 수 있다. 파일에는 이름·프롬프트·스케줄 등 이식 가능한 정보가 포함되지만 작업 공간, provider, 모델, 권한, 활성화 상태, 실행 기록은 포함되지 않는다. 가져온 사용자가 실행 환경을 다시 선택한다.

이름이나 설정 편집, 활성화·비활성화, 복제, 실행 중지, 삭제가 가능하다. 삭제는 자동화와 실행 기록을 영구 제거한다.

## 핵심 요약

Automations는 확인된 프롬프트와 세션 설정을 일정에 따라 반복 실행한다. 먼저 수동 실행으로 결과를 검증하고, 무인 실행 전에는 권한·실행 머신·모델 사용량을 점검한다.
