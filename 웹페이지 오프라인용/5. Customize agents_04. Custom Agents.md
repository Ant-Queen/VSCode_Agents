# Custom Agents 요약

- 원문: https://code.visualstudio.com/docs/agent-customization/custom-agents
- 문서 제목: Custom agents in VS Code
- 원문 수정일: 2026-08-19

## Custom agent란

Custom agent는 특정 개발 역할에 맞게 AI의 persona, 지침, 사용 도구, 모델을 묶은 구성이다. 계획·보안 리뷰·아키텍처·구현 등 작업별 에이전트를 만들어 매번 설정을 반복하지 않을 수 있다.

Custom agent는 `.agent.md` Markdown 파일로 정의하며 workspace에서는 팀과 공유하고, user profile에서는 여러 작업 공간에서 재사용한다. Copilot과 Cloud harness에서도 사용할 수 있다.

## Handoff

Handoff는 에이전트 간의 순차 워크플로를 만든다. 예를 들어 Planning → Implementation, Implementation → Review, 실패 테스트 작성 → 통과 구현 흐름을 버튼으로 연결한다.

frontmatter의 `handoffs`에 대상 agent, 버튼 label, prompt, 선택적 `send`와 `model`을 지정한다. 사용자가 버튼을 누르면 관련 컨텍스트가 전달되고, `send: true`이면 프롬프트가 자동 제출된다.

## 위치와 파일 형식

- Workspace: `.github/agents`
- Claude 형식: `.claude/agents`
- User: `~/.copilot/agents`

`.agent.md` frontmatter에서 `name`, `description`, `argument-hint`, `tools`, `agents`, `model`, `user-invocable`, `disable-model-invocation`, `target`, `mcp-servers`, `handoffs`, Preview `hooks`를 설정할 수 있다.

`tools`는 내장·도구 세트·MCP·확장 도구를 지정한다. `agents`는 호출 가능한 서브에이전트를 제한하며, `[]`이면 사용하지 않는다. 본문에는 에이전트가 따라야 할 구체적인 지침과 도구 참조를 Markdown으로 작성한다.

## 생성과 관리

`/agents`, Agent Customizations editor의 Agents 탭, `Chat: New Custom Agent` 명령으로 생성한다. `/create-agent`로 역할 설명을 바탕으로 AI 생성을 요청할 수 있다.

Agents dropdown의 Configure Custom Agents에서 eye 아이콘으로 표시 여부를 조절한다. 파일을 삭제하거나 목록의 trash 아이콘으로 완전히 제거한다. 기존 `.chatmode.md`는 `.agent.md`로 이름을 바꾸어 변환할 수 있다.

## 도구 우선순위와 공유

Prompt file과 custom agent에서 모두 도구를 지정하면 prompt file이 우선한다. 팀 공유는 `.github/agents`에 저장하고, 조직 범위 agent는 `github.copilot.chat.organizationCustomAgents.enabled`로 발견할 수 있다.

Monorepo의 상위 저장소 agent를 사용하려면 `chat.useCustomizationsInParentRepositories`를 켠다. Agent Host는 프로필 user data가 아니라 `~/.copilot/agents`를 읽으므로 사용자 맞춤화 migration이 필요할 수 있다.

## 보안

계획 agent에는 읽기 전용 도구만, 구현 agent에는 편집 도구를 주는 등 역할에 필요한 최소 도구만 허용한다. hook과 MCP 서버를 포함한 agent 파일은 명령을 실행할 수 있으므로 출처와 내용을 검토한다.

## 핵심 요약

Custom agents는 역할·도구·모델·지침을 작업별로 고정하고 handoff로 다음 단계를 연결한다. 파일 위치와 frontmatter를 정확히 구성하고, 각 역할에는 필요한 최소 권한만 제공해야 한다.
