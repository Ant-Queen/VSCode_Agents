# Chat Interaction Controls 요약

- 원문: https://code.visualstudio.com/docs/chat/chat-overview
- 문서 제목: Use chat in VS Code
- 원문 수정일: 2026-10-07

## 요청과 진행 제어

Chat view, 채팅 편집기 탭, Agents window에서 같은 채팅 조작 기능을 사용할 수 있다. 요청을 입력해 Enter 또는 Send를 누르고, 진행 중에는 새 메시지 처리 방식을 선택한다.

- **Add to Queue**: 현재 응답이 끝난 후 메시지를 보낸다.
- **Steer with Message**: 현재 도구 실행이 끝나면 방향을 바꾸고 새 메시지를 처리한다.
- **Stop and Send**: 현재 요청을 취소하고 새 메시지를 바로 보낸다.

중단은 이미 완료된 파일 수정, 터미널 명령, 외부 작업을 되돌리지 않는다. 파일과 채팅을 되돌릴 때는 checkpoint를 복원한다. 기본 전송 동작은 `chat.requestQueuing.defaultAction`으로 설정한다.

## 컨텍스트와 명령

현재 파일·선택 영역은 암묵적 컨텍스트가 될 수 있다. `#` 멘션으로 파일, 폴더, 심볼, 코드베이스, 터미널 선택 영역, 도구를 지정하고 이미지나 통합 브라우저 요소를 추가할 수 있다. `/` 명령은 자주 쓰는 작업이나 Agent Skills를 호출한다.

Agent Host 세션에서는 입력 첫 글자로 `!`를 쓰면 메시지를 모델에 보내지 않고 기본 셸에서 터미널 명령을 실행한다.

## 대화 탐색과 표시

`Ctrl+F`로 대화의 프롬프트와 응답을 검색한다. `Ctrl+Alt+Up/Down`은 이전·다음 프롬프트, `Ctrl+Alt+PageUp/PageDown`은 이전·다음 코드 블록으로 이동한다. OS 알림은 `chat.notifyWindowOnResponseReceived`와 `chat.notifyWindowOnConfirmation`으로 제어한다.

채팅 글꼴·코드 글꼴·줄 바꿈·요청 시각 등을 설정할 수 있다. Agents window에는 채팅 배경 사용자 지정 기능도 제공된다. 접근성 확인에는 Open Accessible View를 사용한다.

## 결과 확인과 품질 개선

변경 파일을 열어 diff를 보고 커밋·통합 전에 테스트한다. 더 나은 결과를 위해 원하는 완료 조건을 구체적으로 쓰고 관련 파일과 심볼을 연결하며, 프로젝트 지침·프롬프트 파일·사용자 지정 에이전트·MCP 및 확장 도구를 활용한다.

예상과 다른 답변이나 동작은 Agent Logs와 Chat Debug view에서 도구 호출, 모델 요청, 프롬프트와 컨텍스트를 확인한다.

## 핵심 요약

채팅 입력은 요청을 보내는 곳인 동시에 컨텍스트와 실행 흐름을 조절하는 인터페이스다. 진행 중 요청은 큐에 넣거나 조정·취소할 수 있지만, 이미 실행된 외부 효과는 별도로 확인하고 복구해야 한다.
