# Copilot Harness Tools 설정 요약

- 원문: https://code.visualstudio.com/docs/agent-customization/tools
- 문서 제목: Manage tools for the Copilot harness
- 원문 수정일: 2026-08-19

## 기능 범위

Agent Customizations의 Tools 탭은 Agent Host에서 실행되는 Copilot harness 세션에 제공할 client-side 도구를 관리한다. 선택 결과는 프로필 전체와 세션 사이에 유지된다.

다른 harness의 요청별 도구 선택은 Chat view의 Configure Tools에서 수행한다.

## 도구 관리

도구 그룹 또는 개별 도구를 검색하고 활성화·비활성화한다. 그룹의 일부만 선택하면 혼합 상태가 표시된다. Copilot 내장 도구는 읽기 전용으로 표시될 수 있고, 연결된 VS Code 클라이언트가 제공하는 도구는 클라이언트 연결 중에 사용할 수 있다.

Marketplace에서 설치한 확장이 제공하는 Language Model Tool도 목록에서 관리한다. 확장 도구 그룹을 제거하면 해당 도구뿐 아니라 확장 전체가 삭제될 수 있으므로 확인한다.

## 승인과의 관계

도구를 활성화하는 것과 도구 실행을 승인하는 것은 별개다. Tools 설정은 에이전트가 선택할 수 있는 기능을 정하고, permission level과 approval 설정은 실행 시 사용자 확인 여부를 정한다.

따라서 필요한 도구만 활성화하고, 파일 편집·터미널·외부 호출에는 별도의 승인과 보안 정책을 적용한다.

## 핵심 요약

Copilot harness의 Tools 맞춤화는 프로필 범위에서 에이전트의 도구 선택지를 관리한다. 도구 제공 여부와 실행 권한은 분리되어 있으므로 최소 도구 원칙과 승인 정책을 함께 사용해야 한다.
