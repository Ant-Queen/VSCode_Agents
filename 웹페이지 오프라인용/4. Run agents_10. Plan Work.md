## Plan agent의 역할

Plan agent는 구현 전에 요구 사항을 정리하고 상세한 구현 계획을 만드는 기능이다. 복잡한 기능, 리팩터링, 버그 수정에서 바로 코드 생성으로 들어가 잘못된 설계나 누락을 줄인다.

Todo list를 사용해 전체 목표와 진행 상태를 추적하며, 계획을 검토·확정한 뒤에만 구현 단계로 넘어간다.

## 계획 생성 절차

1. Chat view에서 `Ctrl+Alt+I`로 채팅을 연다.
2. agents dropdown에서 **Plan**을 선택한다.
3. 작업 내용을 높은 수준으로 입력한다. 예: OAuth2·JWT 인증 시스템 구현
4. 또는 `/plan` 뒤에 작업을 입력해 바로 계획 모드로 전환한다.
5. 에이전트가 조사 후 질문하면 답한다.
6. 생성된 계획의 요약, 구현 단계, 검증 단계를 검토한다.
7. 후속 프롬프트로 계획을 반복 개선한다.
8. 계획이 완성되면 구현을 시작하거나 편집기에서 추가 검토한다.

확정된 계획은 **Start Implementation**에서 구현 에이전트를 선택해 전달할 수 있다. 계획과 대화 컨텍스트가 구현 에이전트로 이어진다.

## 계획의 세션 memory

Plan agent는 구현 계획을 `/memories/session/plan.md`에 자동 저장한다. Chat: Show Memory Files 명령으로 확인할 수 있지만 세션이 끝나면 session memory가 삭제되므로 다음 세션에서 자동으로 사용할 수 없다.

## 맞춤화

팀의 설계 규칙에 맞게 별도의 Custom planning agent를 만들 수 있다. 계획과 구현에 사용할 모델은 다음 설정으로 지정한다.

- `chat.planAgent.defaultModel`: Plan agent 기본 모델
- `github.copilot.chat.implementAgent.model`: 구현 단계 모델
- `github.copilot.chat.planAgent.additionalTools`: 계획 조사 단계에 추가할 도구(Preview)

추가 도구로 MCP 서버를 연결해 내부 자료를 조사할 수도 있다.

## 핵심 요약

Plan agent는 조사·질문·설계·검토를 거쳐 실행 가능한 계획을 먼저 만든다. 계획을 승인한 뒤 구현 에이전트로 핸드오프하면 요구 사항과 검증 기준을 유지한 채 구현을 시작할 수 있다.
