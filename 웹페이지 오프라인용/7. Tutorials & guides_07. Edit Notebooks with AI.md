# Edit Jupyter Notebooks with AI 요약

- 원문: https://code.visualstudio.com/docs/agents/guides/notebooks-with-ai
- 문서 제목: Edit Jupyter notebooks with AI in VS Code
- 원문 수정일: 2026-08-19

## 새 노트북 생성

`/newNotebook` 뒤에 분석 목적과 사용할 라이브러리를 입력하거나 Agent에 자연어로 요청한다. AI는 Markdown과 코드 셀로 구성된 `.ipynb` 파일을 만들고 데이터 읽기·분석·시각화 코드를 배치한다.

## 셀 편집과 실행

기존 셀에서 `Ctrl+I`로 Inline Chat을 열어 코드 수정이나 새 셀 생성을 요청한다. `#변수명`으로 현재 커널 변수를 컨텍스트에 추가할 수 있다. 변경 후 Accept 또는 Accept and Run을 선택한다.

여러 셀에 걸친 변경과 반복 작업은 Chat의 Agent에 맡긴다. 에이전트는 필요하면 셀을 실행하고 결과를 확인하며 다음 변경을 수행한다.

## 출력과 데이터 분석

셀 출력의 메뉴에서 Add Cell Output to Chat을 선택하면 차트, 표, 오류와 같은 결과를 질문 컨텍스트로 첨부할 수 있다. Agent에게 데이터 분석을 요청하면 데이터 정제, 시각화, 통계 분석을 수행하는 노트북을 구성하고 셀을 실행한다.

도구와 셀 실행은 승인 요청을 발생시킬 수 있으므로 실행 결과와 생성된 코드를 검토한다.

## 핵심 요약

VS Code의 AI 노트북 기능은 생성, 셀 단위 편집, 다중 셀 변경, 출력 기반 질문, 데이터 분석을 지원한다. 커널 변수와 셀 출력을 필요한 컨텍스트로 추가하고, 실행 결과를 검증하며 변경을 수락해야 한다.
