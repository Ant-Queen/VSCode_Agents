# Test with GitHub Copilot 요약

- 원문: https://code.visualstudio.com/docs/agents/guides/test-with-copilot
- 문서 제목: Test with GitHub Copilot
- 원문 수정일: 2026-08-19

## 지원하는 테스트 작업

Copilot은 테스트 프레임워크 설정, 단위·통합·E2E 테스트 생성, edge case 추가, 실패 테스트 분석과 수정에 도움을 준다. `/setupTests`로 프로젝트에 맞는 프레임워크와 VS Code 확장 설정을 안내받을 수 있다.

## 테스트 생성

Chat이나 Inline Chat에서 테스트 생성을 요청하거나 편집기에서 **Generate Code > Generate Tests**를 선택한다. 프롬프트에 프레임워크, 파일 구조, 명명 규칙, 기존 패턴, 단위·통합·E2E 범위와 필요한 경계 조건을 명시한다.

## 실패 테스트 수정

Test Explorer에서 실패한 테스트의 Fix Test Failure를 선택하거나 `/fixTestFailure`를 사용한다. Agent는 실행 결과를 확인하고 원인을 분석해 수정 후 다시 실행할 수 있다.

생성된 테스트가 실제 요구 사항과 프로젝트 규칙을 검증하는지, 단순 구현을 그대로 확인하는 취약한 테스트가 아닌지 사람이 검토한다.

## 핵심 요약

Copilot은 테스트 작성과 실패 수정의 속도를 높이지만 테스트의 범위·경계 조건·검증 가치까지 자동 보장하지 않는다. 프로젝트의 기존 패턴과 명확한 acceptance criteria를 제공하고 결과를 직접 검토해야 한다.
