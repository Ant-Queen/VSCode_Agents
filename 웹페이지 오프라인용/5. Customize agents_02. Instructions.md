# Custom Instructions 요약

- 원문: https://code.visualstudio.com/docs/agent-customization/custom-instructions
- 문서 제목: Use custom instructions in VS Code
- 원문 수정일: 2026-08-19

## Custom instructions란

Custom instructions는 AI가 코드를 생성하고 개발 작업을 수행할 때 따를 공통 규칙을 Markdown으로 정의한다. 매번 같은 컨텍스트를 프롬프트에 반복하지 않고 프로젝트의 표준, 아키텍처, 보안, 문서 규칙을 일관되게 적용할 수 있다.

Inline suggestions에는 custom instructions가 적용되지 않는다.

## 지침 파일 유형

### Always-on instructions

- `.github/copilot-instructions.md`: 작업 공간의 모든 채팅 요청에 자동 적용한다.
- `AGENTS.md`: 여러 AI 에이전트와 공유하거나 하위 폴더별 지침에 사용한다.
- 조직 지침: GitHub 조직의 여러 저장소에 적용한다.
- `CLAUDE.md`: Claude Code와 호환되는 항상 적용 지침이다.

### File-based instructions

`*.instructions.md` 파일은 `applyTo` glob 패턴이나 작업 설명이 일치할 때 적용한다. 언어·프레임워크·폴더·테스트 파일별 규칙에 적합하다.

기본 위치는 workspace의 `.github/instructions`, Claude 형식은 `.claude/rules`, 사용자 지침은 `~/.copilot/instructions`와 `~/.claude/rules`다. `chat.instructionsFilesLocations`로 추가 위치를 설정할 수 있다.

## 파일 형식

`.instructions.md`는 선택적 YAML frontmatter와 Markdown 본문으로 구성한다.

```yaml
---
name: Python Standards
description: Python coding conventions
applyTo: '**/*.py'
---
```

`applyTo: '**'`는 모든 파일에 적용한다. 지정하지 않으면 자동 적용되지 않지만 채팅에 수동으로 첨부할 수 있다. 여러 지침 파일이 있으면 모두 컨텍스트에 추가되지만 적용 순서는 보장되지 않는다.

## 생성과 적용

- `/instructions`로 Configure Instructions 메뉴를 연다.
- Agent Customizations editor에서 New Instructions를 선택한다.
- `Chat: New Instructions File` 명령으로 파일을 만든다.
- `/create-instruction`으로 AI에게 특정 규칙 파일을 생성하게 한다.
- `/init` 또는 `/create-instructions`는 프로젝트 전체 지침 생성을 돕는다.

현재 대화에서 에이전트의 반복 실수를 발견했다면 `extract an instruction from this`처럼 요청해 해당 교정을 지침으로 추출할 수 있다.

## 권장 작성법

지침은 짧고 프로젝트에 특화되어야 한다. 명명·라이브러리·아키텍처·오류 처리·보안·테스트·문서화·완료 조건을 명확히 적고, 일반적인 조언과 오래된 규칙은 제거한다. 관련 파일은 Markdown 링크로 참조한다.

`AGENTS.md`는 `chat.useAgentsMdFile`로 활성화하고, 하위 폴더 검색은 `chat.useNestedAgentsMdFiles`로 제어한다. Claude 지침은 `paths` 속성으로 적용 범위를 지정한다.

## 핵심 요약

Always-on 지침은 프로젝트 전체 규칙에, `.instructions.md`는 파일·작업별 규칙에 사용한다. 가장 좁은 적용 범위와 구체적인 규칙으로 시작하고, `/init`이나 `/create-instruction`으로 생성한 결과를 반드시 검토해야 한다.
