## 도구 선택과 사용

에이전트는 요청과 컨텍스트에 따라 활성화된 도구 중 적절한 것을 선택한다. 도구로 파일·코드 조사, 명령 실행, 웹 확인, 브라우저 검증, MCP 및 확장 기능 호출을 할 수 있다. 먼저 Agent를 선택하고 목표와 검증 조건을 설명한 뒤, 진행 중 도구 호출과 결과를 확인한다.

특정 도구나 도구 묶음을 지시하려면 입력창에서 `#`을 사용한다. Tools 탭에서 도구 그룹 또는 개별 도구를 켜고 끌 수 있다. Copilot 도구 구성은 Agent Customizations에서 관리하며 프로필에 저장된다. 활성화는 사용 가능 여부만 바꾸며 승인 권한을 우회하지 않는다.

## 도구 공급자와 입력 검토

Built-in 도구 외에 MCP 서버나 도구 제공 확장을 설치할 수 있다. 확장 Marketplace 탐색은 기본 VS Code 창에서 수행한다. 확장 도구의 확인 대화상자는 입력값을 편집할 수 있는 경우가 있지만 Agent Host의 일반·터미널 호출은 읽기 전용이다. 실행 전 도구 입력과 결과를 확인한다.

## 터미널과 백그라운드 작업

통합 terminal 도구로 명령을 실행하고 대화에서 출력이나 통합 터미널을 확인한다. 장시간 서버·watch 명령은 Continue in Background로 넘겨 다른 작업을 이어갈 수 있다. 완료된 백그라운드 작업 출력은 대화에서 다시 확인할 수 있다.

## 도구 제한

요청당 도구 한도 오류가 나면 활성 도구 수를 줄이거나 도구 구성을 정리한다. 작업과 무관한 도구를 끄면 컨텍스트를 줄이고 에이전트가 필요한 기능에 집중하게 할 수 있다. 반복 가능한 브라우저 검증은 저장소의 테스트로 남겨 CI에서 재사용한다.

## 핵심 요약

도구는 에이전트의 실제 작업 능력을 결정한다. 필요한 도구만 활성화하고, 권한과 도구 가용성을 별도로 이해하며, 실행 매개변수와 출력 결과를 검토한다.
