# Agent Customization 요약

- 원문: https://code.visualstudio.com/docs/agents/concepts/customization
- 문서 제목: Understand agent customization
- 원문 수정일: 2026-10-07

## 왜 사용자 지정이 필요한가

모델은 일반적인 지식은 갖추고 있지만, 팀의 규칙, 프로젝트 구조, 사용자 취향, 도구 세트는 모른다. 사용자 지정은 에이전트가 특정 환경에 맞게 동작하도록 만드는 메커니즘이다.

## 사용자 지정의 종류

- 지침(instructions): 프로젝트 규칙이나 코딩 표준을 제공
- 에이전트 스킬: 특정 태스크를 수행하는 재사용 가능한 워크플로우
- 커스텀 에이전트: 특정 역할, 도구, 모델 조합을 가진 전용 에이전트
- MCP: 외부 서비스와 연결하는 도구 확장
- 훅(hooks): 에이전트 라이프사이클에 따라 강제 실행되는 자동 동작
- 플러그인: 관련 사용자 지정을 묶어 배포

## 모델 기반 동작 vs 결정적 동작

대부분의 사용자 지정은 모델이 판단할 수 있도록 안내하는 형태다. 하지만 훅은 특정 이벤트가 발생하면 반드시 실행되는 결정적 동작이다.

예:

- 지침: "React 파일에서는 스타일 규칙을 따른다"처럼 모델의 선택을 안내
- 훅: 파일 수정 후 자동 포맷 실행

## 조합 방식

사용자 지정은 서로 배타적이지 않고 함께 조합할 수 있다.

예시:

1. 프로젝트 표준 지침 추가
2. 특정 작업용 커스텀 에이전트 정의
3. 에이전트 스킬로 반복 작업 자동화
4. MCP로 이슈 트래커나 DB 연결
5. 훅으로 검증 및 포맷 강제

## 범위 선택

사용자 지정은 적용 범위를 정할 수 있다.

- 사용자: 개인 설정
- 워크스페이스/저장소: 프로젝트 단위 공유
- 조직: 팀 또는 조직 전체 적용

## 핵심 요약

에이전트 사용자 지정은 프로젝트에 맞는 규칙, 반복 작업, 외부 연결, 자동 검증을 추가하는 방법이다. 잘 설계된 사용자 지정은 에이전트의 반복 실수를 줄이고, 동일한 작업을 더 일관되게 수행하게 해준다.
