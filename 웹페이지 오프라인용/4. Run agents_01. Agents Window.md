# Agents Window 요약

- 원문: https://code.visualstudio.com/docs/agents/run/agents-window
- 문서 제목: Use the Agents window (Preview)
- 원문 수정일: 2026-08-19

## Agents window란

Agents window는 채팅을 중심으로 여러 작업 공간의 에이전트를 한 창에서 관리하는 전용 VS Code 창이다. 높은 수준의 작업을 할당하고, 결과를 검토하며, 여러 세션을 병렬로 실행·추적하는 agent-first 작업에 적합하다.

현재 Preview 기능이며, Chat view와 같은 세션·설정·키 바인딩을 공유하므로 필요할 때 코드 중심의 Chat view로 전환할 수 있다.

## 열기

- 제목 표시줄의 **Open in Agents** 선택
- 명령 팔레트의 `Chat: Open Agents Window` 실행
- 환영 페이지의 Agents window 링크 선택
- 명령줄에서 `code --agents` 실행
- 브라우저에서 `https://insiders.vscode.dev/agents` 열기

기본적으로 GitHub 인증이 필요하다. 실험적으로 Claude 자격 증명이나 ChatGPT 로그인이 있으면 `chat.agentHost.allowSignedOutWhenUsable` 설정을 통해 GitHub 로그인 없이 데스크톱 Agents window를 사용할 수 있다. 브라우저 버전은 GitHub 로그인이 필요하다.

## 화면 구성

- **Sessions list**: 작업 공간 전체의 세션을 보고 관리한다.
- **Customizations panel**: 에이전트 맞춤화를 관리한다.
- **Chat area**: 활성 세션의 대화를 확인하고 프롬프트를 입력한다.
- **Changes panel**: 세션의 변경 사항과 Git 작업을 검토한다.
- **Files panel**: 활성 세션의 작업 공간 파일을 탐색한다.

세션을 선택하면 Chat, Files, Changes, Terminal·Tasks, Browser가 해당 세션 기준으로 갱신된다. Quick chat은 작업 공간과 연결되지 않으므로 Files와 Changes가 표시되지 않는다.

## 세션 시작

1. 사이드바에서 **New** 또는 `Ctrl+N`을 선택한다.
2. 로컬 폴더, GitHub 저장소, SSH·개발 터널 원격 작업 공간을 선택한다.
3. 작업 공간 신뢰 여부를 확인한다.
4. Copilot, Claude, Codex 등 사용 가능한 하니스를 선택한다.
5. 에이전트, 모델, 권한 수준, 격리 모드를 설정한다.
6. 목표를 설명하는 프롬프트를 입력한다.

새 세션을 백그라운드에서 시작하려면 `Alt+Enter`를 사용한다. Quick chat은 작업 공간과 무관한 질문이나 작업에 사용하며, Chats 영역의 `+`로 시작한다.

## 검토와 검증

작업이 끝나면 Files에서 파일을 확인하고 Changes에서 변경 범위를 검토한다. diff의 특정 영역에 피드백을 남기거나, 통합 브라우저에서 앱을 실행하고, Tasks·터미널·테스트·디버거로 결과를 검증한다. 검토 후에는 변경 사항을 커밋하거나 적절한 통합 작업을 수행한다.

## 여러 세션과 맞춤화

세션을 작업 공간·시간별로 그룹화하고, 고정하거나 드래그해 순서를 바꿀 수 있다. 세션을 나란히 열어 결과를 비교하고, Agent Host 세션에서는 하나의 세션 안에 여러 독립 채팅도 배치할 수 있다.

Customizations 패널에서 agents, skills, instructions, hooks, MCP 서버, plugins를 관리한다. Agents window는 기본 VS Code 프로필과 설정을 공유하며, `extensions.supportAgentsWindow`로 확장을 선택적으로 활성화할 수 있다.

## 제한 사항

- Multi-root 세션은 아직 지원하지 않는다.
- Agents window의 agents 드롭다운에는 Plan agent가 직접 표시되지 않을 수 있으며 `/plan`으로 사용할 수 있다.
- Copilot Cloud는 GitHub 기반 저장소에서만 지원된다.
- Local harness와 OpenAI 확장을 통한 Codex 세션은 주로 기본 VS Code 창에서 사용한다.

## 핵심 요약

Agents window는 여러 프로젝트의 에이전트 작업을 한 곳에서 조정하고, 세션별 파일·변경·브라우저·터미널 상태를 함께 관리하는 인터페이스다. 큰 목표를 위임한 뒤 diff와 실제 실행 결과를 검증하는 흐름에 적합하다.
