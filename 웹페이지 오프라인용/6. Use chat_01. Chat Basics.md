# Chat Basics 요약

- 원문: https://code.visualstudio.com/docs/chat/chat-overview
- 문서 제목: Use chat in VS Code
- 원문 수정일: 2026-08-19

## Chat 표면 선택

VS Code는 Chat view, Agents window, Inline Chat, Quick Chat 등 작업 방식에 맞는 여러 대화 표면을 제공한다. Chat view는 코드 옆에서, Agents window는 여러 프로젝트의 에이전트를 조정하는 데 적합하다. Inline Chat은 현재 코드의 국소 편집, Quick Chat은 작업 공간과 무관한 가벼운 질문에 사용한다.

주요 단축키는 Chat view `Ctrl+Alt+I`, Inline Chat `Ctrl+I`, 새 세션 `Ctrl+N`이다.

## 컨텍스트와 명령

`/` slash command로 prompt file, skill, plan, debug, compact, fork 같은 기능을 호출하고, `#` mention으로 파일·폴더·심볼·도구·터미널 결과·변경사항을 추가한다. `@` participant는 전문 Chat participant를 호출한다.

`!`로 시작하는 입력은 Agent Host에서 터미널 명령을 직접 실행하므로 일반 에이전트 요청과 구분해야 한다. Explorer·Search·편집기 탭의 항목을 채팅으로 드래그할 수도 있다.

## 대화 제어

에이전트가 작업 중 새 메시지를 보내면 대기열에 추가하거나, 현재 작업을 steer하거나, 현재 작업을 중지하고 새 요청을 보낼 수 있다. 작업 종료 후에는 변경 파일을 diff로 검토하고, 필요하면 후속 요청·직접 편집·checkpoint 복원을 사용한다.

## 검토와 알림

`chat.checkpoints.showFileChanges`로 요청별 변경 요약을 표시한다. `chat.notifyWindowOnResponseReceived`, `chat.notifyWindowOnConfirmation`으로 응답·승인 알림을 조절하고 `chat.verbose`로 요청·완료 시간을 표시한다.

Chat의 `Ctrl+F` 검색은 프롬프트·응답·코드 블록을 찾지만 Quick Chat·Inline Chat과 접힌 tool pill은 검색하지 않는다.

## 디버깅

Agent Logs와 Chat Debug view에서는 도구 호출, LLM 요청, 시스템·사용자 프롬프트, 컨텍스트, tool payload를 확인할 수 있다. 예상과 다른 결과의 원인을 도구 미호출, 컨텍스트 누락, 맞춤화 미적용 관점에서 추적한다.

## 핵심 요약

VS Code Chat은 질문, 코드 편집, 에이전트 실행, 컨텍스트 첨부를 하나의 흐름으로 연결한다. 작업 표면을 목적에 맞게 고르고, 필요한 context만 추가하고, 변경·도구·검증 결과를 직접 검토해야 한다.
