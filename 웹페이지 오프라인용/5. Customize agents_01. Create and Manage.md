# Create and Manage Agent Customizations 요약

- 원문: https://code.visualstudio.com/docs/agent-customization/overview
- 문서 제목: Create and manage agent customizations
- 원문 수정일: 2026-08-19

## Agent Customizations editor

Agent Customizations editor는 instructions, skills, agents, hooks, MCP 서버, plugins를 한 곳에서 발견·생성·관리하는 중앙 편집기다. 문법 강조와 형식 검증을 제공하며, Chat input에서 선택한 하니스 범위로 맞춤화를 관리한다.

Chat view에서는 Configure Chat 또는 `Chat: Open Customizations`, Agents window에서는 사이드바의 Customizations 항목으로 연다.

## 맞춤화 생성

Overview 탭에서 자연어로 원하는 맞춤화를 설명하면 AI가 필요한 정보를 질문하고 적절한 형식의 파일을 생성한다. 직접 만들 때는 `Chat: New <customization-type>` 명령이나 편집기의 New 메뉴를 사용해 사용자 또는 작업 공간 범위와 이름을 지정한다.

MCP 서버와 agent plugin은 해당 탭의 Marketplace에서 찾아 설치하고 관리할 수 있다.

## 적용 범위

- **User**: 모든 작업 공간에서 개인적으로 사용하며 프로젝트에 커밋하지 않는다.
- **Workspace**: 프로젝트 기여자와 Source Control로 공유한다.
- 일부 유형은 조직 범위도 지원하지만 모든 맞춤화가 모든 범위를 지원하지는 않는다.

Agent Host 세션은 Copilot의 `~/.copilot`, Claude의 `~/.claude` 같은 하니스 중립 사용자 폴더를 읽는다. VS Code 프로필 user data에만 있는 사용자 맞춤화는 Agent Host가 읽지 않으므로 migration 기능을 사용해야 한다.

## 사용자 맞춤화 migration

`chat.customizations.userDataMigration.enabled`를 켠 뒤 Customizations editor에서 Migrate User Data Customizations를 선택한다. 옮길 agents와 instructions를 검토하고, 원본 파일을 삭제할지 결정한다. 마이그레이션된 파일은 Settings Sync로 장치 간 동기화되지 않는다.

## 평가와 개선

Chat Customizations Evaluations 확장은 skills, agents, instructions, prompt files를 분석해 모호한 표현, 논리·행동·형식 충돌, persona 불일치, 과도한 복잡성, 누락된 오류 경로를 진단한다. `Chat Customizations Evaluations: Analyze`를 실행하면 Problems panel에 위치별 진단이 표시되고 Implement Suggestions로 개선안을 적용할 수 있다.

Skill은 Waza framework로 테스트 케이스 기반 평가를 수행할 수 있다. `/analyze-prompt`로 채팅에서 분석을 시작할 수도 있다.

## Monorepo와 문제 해결

하위 폴더만 열었을 때 저장소 루트 맞춤화를 찾으려면 `chat.useCustomizationsInParentRepositories`를 켠다. VS Code는 작업 공간에서 Git 루트까지 올라가 모든 customization 유형을 검색한다.

맞춤화가 적용되지 않거나 예상과 다르게 동작하면 `Developer: Open Agent Debug Panel` 또는 Chat의 Show Agent Debug Logs로 발견 과정과 적용 상태를 확인한다.

## 핵심 요약

Agent Customizations editor는 AI 맞춤화의 생성·검증·관리를 통합한다. 개인·프로젝트·조직 범위 중 가장 좁은 범위를 선택하고, 생성 후 평가 도구와 Agent Debug Logs로 실제 적용 여부를 확인해야 한다.
