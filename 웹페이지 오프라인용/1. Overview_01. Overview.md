# VS Code Agents Overview 요약

- 원문 수정일: 2026-08-19

## 문서 개요

VS Code의 에이전트 코딩은 AI 에이전트가 소프트웨어 개발 작업을 일정 수준의 자율성으로 수행하도록 하는 기능이다. 사용자는 높은 수준의 목표를 제시하고, 에이전트는 필요한 컨텍스트를 수집하고 작업을 계획한 뒤 파일 수정, 명령 실행, 결과 검증과 반복 작업을 수행한다.

에이전트는 작업 과정을 대신 결정하지만, 사용자는 에이전트의 행동을 안내하고 결과를 검토하며 실제 변경 사항을 적용할지 결정한다.

## 에이전트로 할 수 있는 일

에이전트는 언어 모델의 추론 능력과 개발 환경에서 동작하는 도구를 결합한다. 따라서 다음과 같이 여러 단계 또는 여러 파일이 관련된 작업에 적합하다.

- 여러 파일에 걸친 기능을 계획하고 구현하기
- 코드베이스 탐색, 리팩터링, 마이그레이션 수행하기
- 오류를 진단하고 테스트를 실행한 뒤 수정 사항 적용하기
- 브라우저 도구로 웹 앱을 실행하고 검증하기
- 서로 독립적인 작업을 병렬 또는 백그라운드에서 수행하기

VS Code의 AI 기능 중 에이전트는 가장 높은 수준의 자율성을 제공한다. 더 가벼운 지원이 필요할 때는 일반 채팅, 인라인 채팅, 인라인 제안, 스마트 작업을 사용할 수 있다.

## 에이전트 코딩의 작동 원리

에이전트 코딩은 다음 세 가지 개념을 중심으로 동작한다.

### 에이전트 루프

에이전트는 언어 모델을 사용해 컨텍스트를 해석하고 도구를 호출한다. 작업이 완료되거나, 사용자 입력이 필요하거나, 사용자가 중지할 때까지 이 과정을 반복한다.

### 세션

세션은 특정 작업의 대화, 작업 공간, 변경 사항, 실행 상태를 보관한다. 이를 통해 작업을 일시 중지하고 나중에 재개하거나 다른 환경으로 인계할 수 있다.

### 하니스와 실행 환경

에이전트 하니스는 에이전트 루프를 조정하고, 실행 환경은 도구가 실행되는 위치와 에이전트가 코드를 변경하는 위치를 결정한다.

에이전트의 동작은 맞춤 설정을 통해 추가로 조정할 수 있다.

## 에이전트와 작업하는 방법

에이전트 세션은 VS Code의 여러 인터페이스와 터미널, 브라우저에서 사용할 수 있다.

- **Agents window**: 높은 수준의 작업을 할당하고 여러 세션을 관리하는 에이전트 중심 인터페이스다. 문서에서는 Preview 기능으로 표시된다.
- **Chat view**: VS Code의 채팅 인터페이스에서 에이전트 세션을 시작하고 이어서 작업할 수 있다.
- **Browser**: 개발 터널을 통해 다른 장치의 브라우저에서 세션에 연결할 수 있다.
- **Copilot CLI 및 기타 하니스**: Copilot CLI, Claude Code, Codex 등 다른 인터페이스와 하니스에서 생성된 지원 세션을 VS Code가 검색할 수 있다.

세션은 특정 인터페이스나 장치에 고정되지 않는다. Agents window와 Chat view 사이를 전환할 수 있고, SSH나 개발 터널을 통해 다른 컴퓨터에서 세션을 시작하거나 관리할 수도 있다.

## 에이전트가 실행되는 위치

### 에이전트 하니스

하니스는 공급자별 기능과 사용 가능한 도구를 결정한다. VS Code는 기본 제공 Local 하니스와 Copilot, Claude, Codex 같은 공급자별 하니스를 지원한다. 지원되는 언어 모델을 선택하거나 로컬에서 실행되는 모델을 포함해 자체 모델을 연결할 수도 있다.

### 실행 환경

- **내 컴퓨터**: 현재 폴더에서 직접 작업하거나 Git worktree를 사용해 변경 사항을 격리한다.
- **클라우드 인프라**: GitHub 저장소에서 백그라운드로 작업하고 결과를 pull request로 받을 수 있다.
- **원격 컴퓨터**: 코드와 도구가 있는 원격 호스트에서 에이전트를 실행한다.

세션을 시작할 때 하니스와 실행 환경을 선택할 수 있으며, 작업의 다음 단계에 더 적합한 대상이 있으면 세션을 인계할 수 있다.

## 사용자의 통제 유지

에이전트는 파일을 읽고 편집하며, 터미널 명령을 실행하고, 외부 서비스를 호출할 수 있다. 사용자는 권한 수준을 설정해 어떤 도구 호출에 승인이 필요한지 정할 수 있다.

운영 체제 수준의 파일 시스템 및 네트워크 제한이 필요하면 에이전트 샌드박싱을 사용한다. 생성된 코드는 반드시 검토하고 결과를 검증한 다음 변경 사항을 유지한다.

조직 관리자는 AI 기능, 모델, 도구의 사용 가능 범위를 중앙에서 제어하고 팀에 필요한 정책을 적용할 수 있다.

## 시작하기

VS Code의 AI 기능은 기본 제공된다. GitHub 계정으로 로그인해 GitHub Copilot 구독을 사용하거나 자체 모델을 연결한 뒤, 다음 학습 경로 중 하나를 선택한다.

1. [Agents Quickstart](https://code.visualstudio.com/docs/agents/quickstart): 에이전트로 작은 앱을 만들고 검증하는 빠른 실습
2. [Agents Tutorial](https://code.visualstudio.com/docs/agents/agents-tutorial): Agents window, Chat view, 소스 제어, 브라우저 도구를 단계적으로 익히는 튜토리얼

에이전트를 사용하려면 `chat.agent.enabled` 설정이 활성화되어 있어야 한다. 조직에서 에이전트를 비활성화한 경우에는 GitHub 조직 관리자에게 문의해야 한다.

## 핵심 요약

VS Code 에이전트는 단순한 코드 제안 기능을 넘어, 목표를 받아 컨텍스트 탐색부터 구현, 실행, 검증까지 이어지는 개발 작업을 수행한다. 사용자는 하니스와 실행 환경을 선택하고, 권한을 통제하며, 결과를 검토하는 방식으로 에이전트의 자율성과 안전성 사이의 균형을 조절한다.
