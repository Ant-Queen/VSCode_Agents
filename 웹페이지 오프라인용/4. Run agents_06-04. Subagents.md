## 서브에이전트를 사용하는 경우

서브에이전트는 주 에이전트가 범위가 분명한 조사·비교·리뷰 과제를 별도 컨텍스트에서 수행하도록 위임하는 기능이다. 구현 전 코드 패턴 조사, 대안 비교, 변경의 성능·정확성·보안 검토처럼 결과를 주 에이전트가 통합할 수 있는 작업에 적합하다. 작은 질문은 직접 처리하는 편이 모델 사용량과 조정 비용을 줄인다.

## 하니스별 동작

어떤 서브에이전트 기능과 설정이 있는지는 harness에 따라 다르다. Copilot harness는 Copilot SDK를 통해 내장 또는 사용자 지정 서브에이전트를 관리한다. Claude·Codex·Local은 각 통합 방식과 제약이 다르므로 VS Code의 harness 안내를 기준으로 설정한다.

서브에이전트가 실행되면 Chat view에서 도구 호출과 활동을 확인할 수 있다. 지원되는 Agents window 세션에서는 읽기 전용 서브에이전트 채팅을 열어 진행 상황을 살펴보고 부모 채팅과 나란히 배치할 수 있다. 읽기 전용 채팅에는 직접 메시지를 입력할 수 없다.

## 대화 표시 설정

리치 렌더링은 서브에이전트를 별도 편집기로 보여준다. `chat.subagents.useRichRendering`을 끄면 활동이 부모 대화 안에 인라인으로 표시된다. `chat.subagents.showCreditUsage`를 켜면 서브에이전트의 AI 크레딧 사용량을 표시한다.

## 사용 시 고려점

각 작업의 범위와 기대 결과를 명확히 정하고, 병렬 과제는 서로 독립적으로 수행 가능하게 나눈다. 서브에이전트의 중간 활동은 메인 대화를 거치지 않지만, 모델 사용량과 결과 통합 비용은 발생한다. 전문 도구와 지침이 필요한 반복 역할은 Custom agent로 정의할 수 있다.

## 핵심 요약

서브에이전트는 메인 대화의 컨텍스트를 덜 소모하면서 독립적인 조사와 리뷰를 병렬 수행한다. 위임 범위를 좁히고 반환 결과를 주 에이전트가 검증·통합하도록 요청한다.
