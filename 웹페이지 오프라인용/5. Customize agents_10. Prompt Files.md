# Prompt Files 요약

- 원문: https://code.visualstudio.com/docs/agent-customization/prompt-files
- 문서 제목: Use prompt files in VS Code
- 원문 수정일: 2026-08-19

## Prompt file이란

Prompt file은 반복 작업을 Markdown 파일로 저장하고 `/name` slash command로 다시 실행하는 재사용 프롬프트다. 목표, 출력 형식, 예시, 필요한 컨텍스트를 한 번 정의해 일관된 작업을 수행한다.

Workspace 기본 위치는 `.github/prompts`, 사용자 prompt는 VS Code 프로필 영역이며 `chat.promptFilesLocations`로 추가 위치를 설정할 수 있다.

## 파일 형식

파일 확장자는 `.prompt.md`이며 YAML frontmatter에서 `description`, `name`, `argument-hint`, `agent`, `model`, `tools`를 지정할 수 있다. 본문은 Markdown 지침으로 작성하고 `${selection}`, `${input:...}`, Markdown 링크, `#tool:<name>`을 사용할 수 있다.

도구 목록은 prompt file의 설정이 참조한 custom agent보다 우선하고, 선택된 agent의 기본 도구보다 우선한다.

## 생성과 실행

- Chat의 `/prompts`로 목록과 메뉴를 연다.
- `Chat: New Prompt File` 또는 Agent Customizations editor에서 만든다.
- `/create-prompt`로 AI에게 생성하게 한다.
- 채팅 입력에서 `/prompt-name`을 실행하거나 Command Palette·편집기의 실행 버튼을 사용한다.

Prompt는 제목·목표·입력·출력·검증 조건을 명확히 적고, 관련 파일과 도구를 명시하는 것이 좋다.

## 제한과 동기화

Agent Host에서 실행되는 일부 에이전트는 prompt file을 직접 사용하지 않으므로, 공통으로 필요한 워크플로는 Agent Skill로 변환하는 것이 적합하다. 사용자 prompt file은 Settings Sync의 **Prompts and Instructions** 항목으로 장치 간 동기화할 수 있다.

적용되지 않거나 도구가 예상과 다르게 선택되면 Agent Debug Log에서 prompt file 발견·도구 우선순위·검색 실패를 확인한다.

## 핵심 요약

Prompt files는 사용자가 필요할 때 호출하는 반복 프롬프트이고, instructions는 자동 규칙, skills는 이식 가능한 전문 워크플로라는 차이가 있다. 실행 환경이 Agent Host인지 확인하고 도구와 입력 변수를 명확히 정의해야 한다.
