# Agent Plugins 요약

- 원문 수정일: 2026-08-19

## Plugin이란

Agent plugin은 skills, MCP 서버, custom agents, hooks, slash commands 같은 맞춤화 요소를 하나의 설치·배포 단위로 묶는다. 반복되는 개발 워크플로를 팀이나 커뮤니티에 일관되게 배포할 수 있다.

Agent Plugins 1.0은 루트 `plugin.json`, `skills/`, `mcp.json`을 사용하는 공개 표준이다. VS Code 전용 기능은 `com.github.copilot/` namespace에 둔다. 기존 Copilot·Claude·OpenPlugin 형식도 지원한다.

## 설치와 관리

`chat.plugins.enabled`로 기능을 활성화하고, Extensions view에서 `@agentPlugins`로 검색하거나 Agent Customizations editor의 Plugins 탭에서 설치한다. Marketplace, Git repository, GitHub Copilot CLI로 설치한 plugin을 사용할 수 있다.

`chat.plugins.marketplaces`로 Marketplace를 추가하고 `chat.pluginLocations`로 로컬 plugin 위치를 등록한다.

## 실행과 lifecycle

Plugin이 활성화되면 포함된 MCP 서버가 시작되고 비활성화되면 중지된다. 설치 과정에서 plugin은 암묵적으로 신뢰될 수 있으므로 게시자와 포함 파일을 먼저 검토한다.

Plugin의 hook matcher는 현재 VS Code에서 무시될 수 있으므로 hook 스크립트가 이벤트 입력을 직접 검사해야 한다. Skill 이름은 일반적인 kebab-case 규칙을 따른다.

## 보안과 문제 해결

Plugin은 hook과 MCP 서버를 통해 명령을 실행하고 외부 시스템에 접근할 수 있다. 출처, `plugin.json`, skill 본문, 서버 명령, 환경 변수, 네트워크 범위를 설치 전 확인한다. 불필요한 plugin은 비활성화한다.

설치 캐시 문제로 동작하지 않으면 `%APPDATA%\Code\agentPlugins\...`의 관련 캐시를 정리한 뒤 재설치하고, Agent Debug Logs에서 발견·실행 상태를 확인한다.

## 핵심 요약

Agent Plugins는 여러 맞춤화를 패키지로 배포해 설치와 재사용을 단순화한다. 내부에 skill·hook·MCP가 포함될 수 있으므로 plugin도 확장 프로그램처럼 신뢰와 권한을 검토해야 한다.
