# Sessions & Handoff 요약

- 원문: https://code.visualstudio.com/docs/agents/concepts/sessions
- 문서 제목: Sessions and handoff
- 원문 수정일: 2026-08-19

## 세션이란

세션은 VS Code에서 에이전트와 수행하는 하나의 작업 단위다. 한 세션에는 단일 대화, 사용자의 프롬프트, 에이전트의 응답과 도구 호출, 작업 중 누적된 컨텍스트가 포함된다.

각 세션은 독립적인 컨텍스트 윈도우를 가지므로 한 세션의 작업이 다른 세션으로 새어 나가지 않는다. 따라서 세션은 작업을 독립적인 스레드로 구성하고 결과를 검토하는 기본 단위다.

## 세션 안의 여러 채팅

하나의 세션에는 여러 채팅을 포함할 수 있다. 각 채팅은 별도의 기록, 제목, 상태, 에이전트 또는 모델 선택을 가지며, 다른 채팅의 대화 기록은 상속하지 않는다. 대신 같은 작업 공간과 코드 격리 영역을 공유한다.

이 기능은 Copilot과 Claude처럼 Agent Host에서 여러 채팅을 지원하는 하니스에서 사용할 수 있다.

## 여러 세션 활용

- **병렬 실행**: 독립적인 작업을 여러 세션에서 동시에 처리한다. 다른 화면으로 이동해도 세션은 계속 실행된다.
- **Fork**: 원본을 보존한 채 다른 구현 방향을 실험한다.
- **Checkpoint와 rollback**: 특정 시점으로 돌아가 일련의 변경을 되돌린다.

## 여러 화면과 외부 세션

Chat view와 Agents window는 같은 세션을 공유한다. 한 화면에서 시작한 작업을 다른 화면에서 계속할 수 있으며, 세션 목록에서 실행 위치와 관계없이 통합해 확인한다.

VS Code는 Copilot CLI, GitHub Copilot 앱, Claude Code, Codex에서 생성된 지원 로컬 세션도 발견할 수 있다. 외부 세션은 VS Code에서 메시지를 보내기 전까지 외부 상태로 표시되며, 이후 Agent Host가 세션을 인계한다.

Agent Host의 에이전트는 다른 세션의 목록과 최근 컨텍스트를 읽고, 새 세션·채팅을 만들거나 세션 간 후속 메시지를 보낼 수도 있다.

## 세션 핸드오프

핸드오프는 대화 기록과 컨텍스트를 유지한 채 세션 대상을 다른 하니스나 실행 환경으로 변경한다. 다음 상황에서 유용하다.

- Copilot에서 Claude 또는 Codex로 전환해 공급자별 기능을 사용한다.
- Plan 에이전트가 만든 검토된 계획을 구현 에이전트에 전달한다.
- 로컬에서 정리한 작업을 Cloud 하니스로 넘겨 원격 실행과 pull request 흐름을 사용한다.

## 원격 및 동기화 세션

세션은 SSH나 개발 터널을 통해 다른 컴퓨터에서 실행할 수 있다. Copilot remote control(`/remote on`)으로 GitHub에서 실행 중인 세션을 관찰하고 조정할 수도 있다.

동기화 세션은 GitHub 계정에 백업되어 여러 장치에서 접근할 수 있다. Session insights를 사용하면 세션 기록을 조회해 과거 작업을 검토할 수 있다.

## 핵심 요약

세션은 대화와 컨텍스트를 하나의 독립된 작업으로 묶으며, 여러 세션을 병렬 실행하거나 fork와 checkpoint로 안전하게 실험할 수 있다. 핸드오프를 사용하면 작업을 유지한 채 하니스, 실행 환경, 장치를 바꿀 수 있다.
