# Debug with GitHub Copilot 요약

- 원문: https://code.visualstudio.com/docs/agents/guides/debug-with-copilot
- 문서 제목: Debug with GitHub Copilot
- 원문 수정일: 2026-08-19

## 디버그 설정

VS Code는 `launch.json`에 디버그 구성을 저장한다. Chat에서 `/startDebugging`을 입력하거나 Django, React Native, Flask 등 프로젝트 유형을 자연어로 설명해 Copilot의 설정 지원을 받을 수 있다.

## 디버그 세션 시작

터미널에서 애플리케이션 시작 명령 앞에 `copilot-debug`를 붙인다.

```bash
copilot-debug node app.js
copilot-debug python manage.py
```

Copilot이 디버그 구성을 만들고 애플리케이션을 디버깅 세션으로 시작한다.

## 오류 수정

Chat 또는 Inline Chat에서 `/fix`, `Fix this #selection`, 입력 검증·리팩터링·성능 개선 같은 프롬프트를 사용한다. 편집기에서 코드를 선택하고 **Generate Code > Fix**를 실행해 수정 제안을 받을 수도 있다.

수정 후에는 diff, 테스트, 디버거 결과를 확인하고 실제 원인이 해결되었는지 검증한다.

## 핵심 요약

Copilot은 디버그 구성 생성, 디버깅 세션 시작, 코드 오류 수정의 세 단계를 지원한다. 자동 생성된 구성과 수정은 편리한 출발점일 뿐이며 실행 결과와 변경 diff를 직접 확인해야 한다.
