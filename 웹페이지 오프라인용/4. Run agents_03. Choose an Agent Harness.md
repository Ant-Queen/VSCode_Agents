# Choose and Use an Agent Harness 요약

- 원문 수정일: 2026-08-19

## 하니스 비교

에이전트 하니스는 세션의 도구 호출, 컨텍스트, 코드 변경을 조정한다. 대부분의 하니스는 VS Code에서 공통 채팅·세션 관리 경험을 제공하지만 실행 위치, 사용 가능한 도구와 모델, 변경 적용 방식이 다르다.

| 하니스 | 실행 위치 | 적합한 작업 |
| --- | --- | --- |
| Local | 내 컴퓨터의 VS Code 확장 호스트 | VS Code·확장 도구와 현재 작업 공간이 필요한 상호작용 작업 |
| Copilot | 내 컴퓨터의 Agent Host | 일반 코딩과 Copilot SDK 기능 |
| Claude | 내 컴퓨터 | Claude의 에이전트 기능, slash command, 권한 모드 |
| Codex | 내 컴퓨터 | OpenAI Codex 기반 대화형·백그라운드 작업 |
| Cloud | 공급자의 원격 인프라 | GitHub 저장소에서 독립적으로 수행하고 pull request로 검토할 작업 |

## 하니스 선택

Chat view나 Agents window에서 새 채팅을 시작하고 **Session Target**을 선택한다. 현재 창에서 사용 가능한 하니스만 목록에 표시된다. 하니스를 진행 중인 세션에서 변경하면 대화 기록과 컨텍스트를 유지하는 핸드오프로 처리된다.

## 코드 격리

코드 격리는 Agents window에서 선택할 수 있다. Chat view 세션은 현재 작업 공간을 사용한다.

- **New Worktree**: 커밋된 기준 브랜치에서 별도 Git worktree를 만들어 병렬 작업과 충돌 방지에 사용한다.
- **Folder**: 현재 폴더에서 작업하며 미커밋·미추적 변경 사항도 볼 수 있다.

Worktree는 Git 저장소에 하나 이상의 커밋이 있어야 한다. 현재 작업 공간의 미커밋 파일과 기본적으로 Git-ignored 파일은 새 worktree에 포함되지 않는다. `git.worktreeIncludeFiles`로 복사할 무시 파일을 지정할 수 있다.

Worktree는 명령과 네트워크를 제한하는 보안 경계가 아니므로 OS 수준 제한에는 샌드박싱을 사용한다.

## 주요 하니스 설정

### Local

현재 작업 공간에서 VS Code 내장 도구, 확장 도구, MCP 서버, BYOK 모델을 사용할 수 있다. Ask, Agent, Plan 역할을 제공하며, 진단·테스트 결과·선택 영역에 즉시 접근해야 하는 작업에 적합하다.

### Copilot

Copilot SDK와 Agent Host를 사용한다. GitHub 인증, 권한 수준, slash commands, remote control(`/remote on`), Copilot CLI 연동과 Research agent Preview를 지원한다. Copilot 세션은 모든 VS Code 도구를 사용할 수 있는 것은 아니며, 프로필 단위 Tools 설정이 필요할 수 있다.

### Claude

Anthropic Claude Agent SDK를 사용한다. GitHub Copilot 구독 또는 Anthropic API key·Claude Code OAuth token으로 인증하며, 자동 편집·승인 요청·계획 권한 모드를 지원한다. `allowDangerouslySkipPermissions`는 격리된 환경에서만 사용해야 한다.

### Codex

OpenAI Codex 확장 또는 실험적 Agent Host 구현을 사용한다. Default Permissions, Auto-Review, Full Access 승인 프리셋을 제공하며 Full Access는 디스크와 네트워크에 제한 없이 접근할 수 있다.

### Cloud

원격 인프라에서 GitHub 저장소의 브랜치에 작업하고 pull request를 만든다. 로컬 편집기 컨텍스트, 터미널 출력, 확장 도구에는 접근하지 못하지만 독립적인 작업과 팀 리뷰에 적합하다. Copilot 세션에서는 `/delegate`로 Cloud에 넘길 수 있다.

## 핸드오프

세션의 Session Target을 열고 Copilot, Claude, Codex, Cloud 중 새 대상을 선택한다. 대화 기록과 컨텍스트는 유지되지만 도구, 권한, 모델은 대상에 따라 바뀐다. Fork는 독립 세션을 만들고, 화면 전환은 하니스와 컨텍스트를 바꾸지 않는다는 점이 다르다.

## 핵심 요약

하니스는 단순한 모델 선택이 아니라 실행 위치, 도구, 권한, 코드 격리와 연결된 세션 실행 방식이다. 현재 작업의 상호작용성, 공급자 기능, 병렬성, 원격 실행과 리뷰 요구를 기준으로 선택해야 한다.
