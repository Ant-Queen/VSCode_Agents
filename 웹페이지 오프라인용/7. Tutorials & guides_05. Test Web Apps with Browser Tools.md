# Test Web Apps with Browser Tools 요약

- 원문: https://code.visualstudio.com/docs/agents/guides/browser-agent-testing-guide
- 문서 제목: Build and validate a web app with browser tools
- 원문 수정일: 2026-08-19

## 목적과 사전 조건

Browser tools는 앱 생성, 브라우저 실행, 사용자 흐름 검증, 오류 수정, 재검증을 하나의 개발 루프로 연결한다. VS Code, Copilot 구독, `workbench.browser.enableChatTools` 활성화가 필요하다.

## 계산기 예제 흐름

먼저 관찰 가능한 acceptance criteria를 정의한다.

- 숫자 버튼이 올바른 값을 입력한다.
- 더하기·빼기·곱하기·나누기가 정확하다.
- Clear가 초기화한다.
- 0으로 나누기는 잘못된 결과 대신 오류를 표시한다.

Chat에서 Integrated Browser가 선택됐는지 확인하고 Agent에게 HTML·CSS·JavaScript 계산기를 만들도록 요청한다. 이후 브라우저에서 각 버튼과 연산을 직접 실행해 기준을 확인한다.

## 수정과 재검증

실패한 기준이 있으면 Agent가 원인을 분석해 코드를 수정하도록 하고, 부분 검사만 하지 말고 전체 acceptance criteria를 다시 실행한다. 최종적으로 각 항목의 결과와 변경 내용을 보고받고 사람이 코드와 검증 결과를 확인한다.

사용자가 직접 연 페이지는 Share with Agent로 공유해야 하며, 공유 페이지는 인증 상태를 사용할 수 있다. Agent가 연 페이지는 격리된 임시 세션이다.

## 확장 시나리오

반응형 레이아웃을 데스크톱·모바일 뷰포트에서 확인하고, 인증 흐름·폼 유효성·접근성·실패 스크린샷을 함께 검증할 수 있다.

## 핵심 요약

웹 앱 테스트는 소스 검토만으로 끝내지 않고 observable criteria를 실제 브라우저에서 수행해야 한다. 실패 시 전체 흐름을 다시 검증하고, 로그인 상태가 필요하면 기존 탭을 명시적으로 공유한다.
