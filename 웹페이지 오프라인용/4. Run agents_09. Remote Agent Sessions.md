# Remote Agent Sessions 요약

- 원문: https://code.visualstudio.com/docs/agents/run/remote-agent-sessions
- 문서 제목: Remote agent sessions
- 원문 수정일: 2026-08-19

## 원격 세션 개요

Agents window는 SSH, 개발 터널 또는 브라우저를 통해 원격 컴퓨터의 에이전트 세션을 시작하고 진행 상황을 확인하게 한다. 원격 머신의 자원과 개발 도구를 사용하거나 모바일 장치에서 작업을 확인할 때 유용하다.

Agents window는 Agent Host Protocol(AHP)을 SSH 또는 개발 터널로 사용한다. 연결할 때 원격 머신에 VS Code CLI를 자동 설치·시작하며, 원격 머신은 켜져 있고 네트워크에서 접근 가능해야 한다.

## SSH 연결

사전 조건은 원격 머신이 SSH로 접근 가능한 것이다. 별도 에이전트 설치는 필요하지 않다.

1. Agents window에서 **New** 또는 `Ctrl+N`을 선택한다.
2. Workspace dropdown의 Remote 탭에서 SSH를 선택한다.
3. `user@hostname` 형식의 SSH 연결 문자열을 입력한다.
4. 원격 폴더를 선택한다.
5. 프롬프트를 입력해 세션을 시작한다.

## 개발 터널 연결

원격 머신에서 개발 터널이 이미 실행 중이어야 한다.

1. New 세션을 만든다.
2. Workspace dropdown의 Remote > Tunnels에서 계정 유형을 선택한다.
3. 활성 터널을 선택한다.
4. 원격 폴더를 선택하고 프롬프트를 보낸다.

개발 터널에는 GitHub 또는 Microsoft 계정 인증을 요구해야 한다. 익명 터널은 URL을 아는 누구나 머신에 접근하고 에이전트 세션을 시작할 수 있으며, 자동 승인 상태라면 사용자 자격 증명으로 명령을 실행할 위험이 있다.

## 브라우저 Agents window

`https://insiders.vscode.dev/agents`에서 설치 없이 브라우저로 Agents window를 사용할 수 있다. 브라우저는 가벼운 클라이언트로 동작하고, 에이전트 세션과 작업 공간 작업은 터널에 연결된 원격 호스트에서 실행된다.

원격 호스트에서 다음 명령을 실행한다.

```bash
code-insiders tunnel
```

Stable 버전은 `code tunnel`을 사용한다. 최초 실행 시 GitHub 또는 Microsoft 계정으로 인증하며, 기본적으로 터널은 인증을 요구한다. 이후 브라우저에서 GitHub로 로그인하고 hosts bar에서 온라인 호스트를 선택한 뒤 폴더, 에이전트, 프롬프트를 지정한다.

## 호스트 상태 관리

브라우저의 hosts bar에서 터널 호스트의 상태를 확인한다.

- **Online**: 연결 가능하며 세션을 시작하거나 계속할 수 있다.
- **Offline**: 호스트에서 터널이 실행되지 않는 상태다.

호스트가 오프라인이면 세션이 disconnected로 표시되고, 다시 온라인이 되면 자동으로 재연결된다.

## 핵심 요약

원격 에이전트 세션은 코드가 있는 머신에서 작업을 실행하고 사용자는 다른 장치에서 제어하게 한다. SSH는 직접 원격 폴더에 연결할 때, 개발 터널은 원격 호스트를 중개할 때 사용하며, 익명 접근은 절대 허용하지 않는 것이 안전하다.
