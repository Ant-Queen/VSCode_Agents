# Agent Skills 요약

- 원문 수정일: 2026-08-19

## Agent Skills란

Agent Skill은 에이전트가 관련 작업을 수행할 때 불러오는 지침, 스크립트, 예시, 리소스의 폴더다. Custom instructions가 코딩 규칙을 정의한다면 skill은 테스트·디버깅·배포 같은 전문 능력과 반복 워크플로를 제공한다.

Skills는 agentskills.io 공개 표준이며 VS Code, Copilot CLI, Copilot cloud agent 등 여러 호환 에이전트에서 사용할 수 있다. 필요한 skill만 on-demand로 로드해 컨텍스트를 절약한다.

## 위치와 생성

프로젝트 skill은 `.github/skills/`, `.claude/skills/`, `.agents/skills/`에, 개인 skill은 `~/.copilot/skills/`, `~/.claude/skills/`, `~/.agents/skills/`에 둔다. `chat.agentSkillsLocations`로 추가 위치를 지정할 수 있다.

각 skill 폴더에는 반드시 `SKILL.md`가 있어야 한다. `/skills`로 설정 메뉴를 열고 Agent Customizations editor에서 New Skill을 선택하거나 `/create-skill`로 AI 생성을 요청한다.

## SKILL.md 형식

```yaml
---
name: webapp-testing
description: Guide for testing web applications with Playwright.
---
```

`name`은 부모 폴더 이름과 같아야 하며 소문자·숫자·하이픈만 사용하고 최대 64자다. `description`은 무엇을 하고 언제 사용하는지 구체적으로 적는다.

선택 필드로 `argument-hint`, `user-invocable`, `disable-model-invocation`, `context`를 사용할 수 있다. `context: fork`는 큰 조사나 최종 결과만 필요한 작업을 별도 서브에이전트 컨텍스트에서 실행한다.

본문에는 목적, 사용 시점, 단계별 절차, 입력·출력 예시, 함께 제공하는 파일 링크를 명확히 작성한다. 스크립트·템플릿·예시는 skill 폴더 안에 둘 수 있다.

## 사용 방식

에이전트는 먼저 frontmatter의 이름과 설명만 보고 관련성을 판단하고, 필요할 때 본문과 참조 리소스를 단계적으로 읽는다. `/skill-name`으로 직접 호출할 수도 있다.

`user-invocable: false`는 slash command에는 숨기지만 자동 로드는 허용한다. `disable-model-invocation: true`는 자동 로드를 막고 수동 호출만 허용한다.

## 공유와 확장

Awesome Copilot이나 Anthropic skills 같은 공유 저장소의 skill은 복사하기 전에 코드와 스크립트를 보안 검토한다. 확장은 `package.json`의 `chatSkills` contribution point로 `SKILL.md` 경로를 제공할 수 있다.

확장 skill 폴더 이름은 `SKILL.md`의 `name`과 일치해야 한다. Monorepo에서는 parent repository customization 검색을 활성화하면 루트 skill도 발견할 수 있다.

## 핵심 요약

Agent Skills는 반복되는 전문 워크플로를 지침·스크립트·리소스와 함께 재사용하는 표준 방식이다. 이름과 설명을 정확히 작성하고, 필요한 리소스를 링크하며, 공유 skill은 실행 전 보안 검토를 해야 한다.
