# Agents 요약

## 핵심 정의

에이전트는 단순한 챗봇이 아니라, 언어 모델과 도구를 조합해 작업을 수행하는 AI 시스템이다. 사용자는 목표를 제시하고, 에이전트는 관련 정보를 찾고, 파일을 읽거나 수정하고, 결과를 검증하면서 반복적으로 작업을 진행한다.

## 에이전트 루프

에이전트는 보통 다음 순서로 동작한다.

1. 이해: 요구사항과 현재 코드 상태를 파악한다.
2. 행동: 파일 읽기, 검색, 편집, 테스트 실행 같은 도구를 사용한다.
3. 검증: 결과를 확인하고 필요한 경우 다시 수정한다.
4. 종료: 목표 달성 여부를 평가하고 최종 결과를 제시한다.

이 반복 과정이 "agent loop"이며, 작업이 커질수록 여러 번 반복된다.

## 통제권

사용자는 여전히 작업을 지시하고, 어떤 행동이 승인되어야 하는지 결정한다. 에이전트는 다음과 같은 방식으로 제어된다.

- 사용할 도구와 권한 설정
- 승인 프롬프트 확인
- 작업 재지시 또는 중단
- 변경된 파일과 검증 결과를 최종적으로 검토

## 세션과 실행 환경

세션은 특정 작업 단위의 대화와 상태를 묶어 관리하는 단위다. 같은 세션 안에서는 여러 채팅을 열어 관련 작업을 병렬로 진행할 수 있다.

에이전트의 실행 환경은 작업을 어느 위치에서 수행할지 결정한다. 로컬, 연결된 호스트, Dev Container, 클라우드 환경 등이 될 수 있다.

## 확장 기능

복잡한 작업에서는 다음 기능을 활용한다.

- 계획(Plan): 구현 전에 조사와 설계
- 서브에이전트: 별도 컨텍스트에서 집중 업무 수행
- 메모리: 세션/저장소/사용자 레벨 메모리 저장
- 사용자 정의 에이전트: 역할, 도구, 모델, 지침을 재사용 가능하게 구성

## 핵심 요약

에이전트는 단순 답변 생성이 아니라 도구를 통해 실제 작업을 수행하는 AI 협업자다. VS Code에서는 세션, 컨텍스트, 도구, 권한, 실행 환경을 함께 조합해 안전하고 반복 가능한 작업 흐름을 만든다.
