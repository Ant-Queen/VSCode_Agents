## 에이전트란

에이전트는 코딩 작업을 자율적으로 계획하고 실행하는 AI 시스템이다. 사용자가 높은 수준의 목표를 제시하면 에이전트가 작업을 단계로 나누고, 도구를 사용해 실행하며, 오류가 발생하면 스스로 수정한다.

언어 모델은 추론과 응답 생성을 담당하고, 에이전트는 모델과 개발 환경 사이에서 도구 호출과 작업 진행을 조정한다.

## 에이전트 루프

에이전트는 다음 세 단계를 반복한다.

1. **이해**: 파일과 코드베이스를 검색하고 문서를 확인해 변경할 내용을 파악한다.
2. **실행**: 코드를 수정하고, 터미널 명령을 실행하며, 의존성을 설치하거나 외부 서비스를 호출한다.
3. **검증**: 테스트와 컴파일 오류를 확인하고 변경 사항을 검토한다. 문제가 있으면 다시 이해·실행 단계를 반복한다.

각 도구의 출력은 다음 판단을 위한 컨텍스트가 된다. 단순한 질문은 몇 번의 파일 읽기로 끝날 수 있지만, 기능 구현은 편집·테스트·오류 수정의 반복으로 진행된다.

## 에이전트 루프 맞춤화

- **Custom agents**: 역할, 지침, 도구, 언어 모델을 조합한 전문 에이전트를 정의한다.
- **Agent skills**: 특정 분야나 작업에 필요한 기능과 절차를 가르친다.
- **Hooks**: 에이전트 루프의 특정 시점에 명령을 실행한다.

## 에이전트와 주변 개념

- **하니스**는 에이전트가 실행되는 런타임과 공급자별 기능을 결정한다.
- **서브에이전트**는 복잡한 작업의 하위 과제를 별도 컨텍스트에서 수행하고 결과를 주 에이전트에 보고한다.
- **세션**은 한 작업의 대화와 누적 컨텍스트를 담는 단위다.
- **메모리**는 사용자, 저장소, 세션 범위의 정보를 다음 작업에서 재사용하게 한다.
- **계획 에이전트**는 코드 변경 전에 조사, 정렬, 설계, 개선의 4단계로 구현 계획을 만든다.

서브에이전트는 컨텍스트를 격리하고, 여러 개를 병렬 실행할 수 있으며, 최종 요약만 주 에이전트에 전달해 토큰 사용을 줄인다.

## 핵심 요약

VS Code의 에이전트는 언어 모델의 추론과 도구 실행을 결합해 이해·실행·검증을 반복한다. 하니스, 세션, 메모리, 계획, 서브에이전트와 맞춤화를 함께 사용하면 작업 규모와 자율성에 맞게 에이전트의 동작을 조정할 수 있다.
