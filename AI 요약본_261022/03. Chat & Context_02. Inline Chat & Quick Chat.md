# Inline Chat과 Quick Chat

- 공식 문서: https://code.visualstudio.com/docs/chat/inline-chat
- 문서 제목: Inline chat and Quick Chat

## 1. 네 가지 작업 화면을 구분하기

Inline Chat과 Quick Chat은 전체 Chat view를 열지 않고도 AI를 사용할 수 있는 가벼운 대화 기능이다. Inline Chat은 현재 코드나 터미널에 붙어 작업하고, Quick Chat은 짧은 질문을 위한 임시 대화창이다. 여러 파일을 조사하거나 복잡한 단계의 작업을 시킬 때는 Chat view를 사용한다.

| 기능 | 주된 목적 | 작업 범위 |
| --- | --- | --- |
| 편집기 Inline Chat | 코드 설명, 국소적인 코드 생성·수정 | 활성 편집기와 선택 영역 중심 |
| 터미널 Inline Chat | 셸 명령 제안, 터미널 관련 질문 | 통합 터미널 |
| Quick Chat | 짧은 질문과 간단한 대화 | 전체 Chat을 열지 않는 빠른 상호작용 |
| Chat view | 다단계 작업, 넓은 프로젝트 조사, 여러 파일 변경 | 대화·도구·프로젝트 컨텍스트를 폭넓게 활용 |

## 2. 편집기에서 Inline Chat 사용하기

1. 편집기에서 대상 파일을 연다. 수정할 부분이 정해져 있다면 코드를 선택한다.
2. `Ctrl+I`를 누르거나 Chat 메뉴에서 **Open Inline Chat**을 선택한다.
3. 원하는 변경이나 질문을 입력하고 `Enter`를 누른다.
4. 제안된 변경을 편집기 안의 diff로 확인한다.
5. 수락하려면 **Keep**, 취소하려면 **Undo**를 선택한다.

선택 영역이 있으면 요청의 초점을 좁힐 수 있다. 선택하지 않은 경우에는 현재 편집기의 코드가 중심이 되지만, 다른 파일의 내용이 컨텍스트에 포함되는지는 환경과 설정에 따라 달라질 수 있다. 중요한 파일은 명시적으로 추가하는 편이 안전하다.

### 기존 Chat 편집 세션과 연결되는 경우

파일이 진행 중인 Chat 편집 세션에 속해 있으면 `Ctrl+I`가 일반 Inline Chat 대신 **Ask in Chat**을 열어 기존 대화의 맥락을 활용할 수 있다. 해당 동작을 원하지 않고 항상 일반 Inline Chat을 사용하려면 `inlineChat.askInChat`을 `false`로 설정한다. 어떤 파일도 활성 Chat 세션에 포함되지 않은 경우에는 이 설정과 관계없이 일반 Inline Chat이 열린다.

선택한 코드 옆에 표시되는 Inline Chat 시작 힌트는 `inlineChat.affordance`로 조절할 수 있다. `off`는 힌트를 숨기고, `gutter`는 줄 번호 영역에, `editor`는 선택 영역 안에 표시한다. 이 힌트는 실험적 기능이며 관련 렌더링 설정의 영향을 받을 수 있다.

## 3. 통합 터미널에서 Inline Chat 사용하기

터미널 Inline Chat은 명령을 제안하거나 터미널 작업을 설명하는 데 유용하다.

1. **View > Terminal**로 통합 터미널을 연다.
2. `Ctrl+I`를 누르거나 Command Palette에서 **Terminal Inline Chat**을 실행한다.
3. 필요한 작업을 자연어로 설명한다. 예: “현재 폴더에서 가장 큰 파일 다섯 개를 확인하는 PowerShell 명령을 제안해줘.”
4. 명령을 충분히 검토한 뒤 선택한다.
   - **Run** (`Ctrl+Enter`): 제안된 명령을 실행한다.
   - **Insert** (`Alt+Enter`): 명령을 터미널 입력란에 넣고, 직접 확인·수정한 뒤 실행한다.

명령은 파일을 수정하거나 데이터를 삭제할 수 있다. 무엇을 대상으로 하는지 확인한 후 실행하고, 영향이 불분명하면 바로 실행하지 말고 명령을 먼저 설명해 달라고 요청한다.

## 4. Quick Chat 사용하기

Quick Chat은 현재 작업 흐름을 벗어나지 않고 짧게 질문할 때 적합하다.

1. `Ctrl+Shift+Alt+L`을 누르거나 Chat 메뉴에서 **Quick Chat**을 선택한다.
2. 질문을 입력하고 `Enter`를 누른다.
3. 파일이나 다른 자료가 필요하면 `#` mention으로 컨텍스트를 추가한다.
4. 대화를 계속 진행해야 한다면 **Open in Chat view**를 선택한다.

Quick Chat에서도 Chat view와 같은 방식의 `#` mention을 사용할 수 있다. 따라서 짧은 질문이라도 필요한 파일이나 심볼을 구체적으로 지정할 수 있다.

## 5. Inline Chat 모델 지정

편집기 Inline Chat의 기본 모델은 `inlineChat.defaultModel` 설정에서 지정한다. 사용 가능한 모델은 Chat의 모델 선택기에서 제공되는 항목에 따라 달라진다.

대화 도중 모델을 변경하면 해당 Inline Chat 세션이 끝날 때까지 선택이 유지된다. VS Code를 다시 불러오면 `inlineChat.defaultModel`에 지정한 값으로 돌아간다.

## 언제 전체 Chat으로 전환할까요?

다음 작업은 Inline Chat보다 Chat view가 적합하다.

- 여러 파일에 걸친 수정이나 코드베이스 전반의 조사
- 설계 검토, 복잡한 리팩터링, 단계별 구현
- 테스트·도구 실행과 결과를 이어서 다뤄야 하는 작업
- 대화 기록과 변경 사항을 계속 검토해야 하는 작업

## 핵심 요약

현재 코드 한 부분은 편집기 Inline Chat, 터미널 명령은 터미널 Inline Chat, 짧은 확인은 Quick Chat으로 시작한다. 변경 diff와 실행 전 명령을 직접 검토하고, 작업 범위가 커지면 Chat view로 이어간다.
