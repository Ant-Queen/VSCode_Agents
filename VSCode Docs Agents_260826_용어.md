- 01. Agents (에이전트)
	- https://code.visualstudio.com/docs/agents/concepts/agents
		- 에이전트 루프 (Agent loop)
			- Prompt →
			- `이해(Understand) → 설정(Act) → 검증(Validate)` 필요한 만큼 반복
			- → Result			
		- 에이전트 루프 맞춤화 (Customize the agent loop)
			- Custom Agent
			- Agent Skills
			- Hooks
		- 에이전트 하니스 (Agent Harnesses)
		- 서브 에이전트 (Subagents)
		- 세션 (Sessions)
		- 메모리 (Memory)
			- 메모리 도구 (Memory tools)
				- 사용자 메모리 (User memory)
				- 저장소 메모리 (Repository memory)
				- 세션 메모리 (Session memory)
			- 코파일럿 메모리 (Copilot memory)
		- 계획 에이전트
			발견(Discover) → 정렬(Alignment) → 설계(Design) → 개선(Refinement)
